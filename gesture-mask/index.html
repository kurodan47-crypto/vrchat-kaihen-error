Gesture Layer needs valid mask on first animator layer（手のマスクが無い）

画面に出る文字：

Gesture Layer needs valid mask on first animator layer

意味

手の形を動かすアニメーター（Gestureレイヤー）を差し替えたとき、1段目のレイヤーに「手だけ動かす」マスクが入っていない状態です。

よくある原因

  • ポーズ・手のギミックを入れて、Gestureのアニメーターを自分のものに差し替えた
  • アニメーターを複製・作り直したときにマスクが外れた

直し方

  1. Animatorウィンドウで、Avatar Descriptor の Gesture に入っているアニメーターを開く
  2. 一番上のレイヤーの歯車を押す
  3. Mask に「vrc_HandsOnly」（VRChat SDKに入っています）を入れる

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自分のプロジェクトで原因を探すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります。
この症状では：1段目のマスクが無いかを調べ、有料版なら1クリックで vrc_HandsOnly を入れます。
改変おたすけ診断（無料版あり）
