VRCFury が入っていない（VRCFury関係のMissing Script・エラー）

画面に出る文字：

The referenced script on this Behaviour is missing! / VF.Model … / VRCFury …

意味

衣装やギミックが前提にしている VRCFury が入っていないか、版が合っていません。

よくある原因

  • VRCFury対応の衣装・ギミックを入れたのに、VRCFury本体を入れていない
  • VRCFuryが古い

直し方

  1. ALCOM（またはVCC）に VRCFury の配布先（https://vcc.vrcfury.com）を追加する
  2. このプロジェクトに VRCFury を入れる（入っていれば最新に更新）
  3. Unityを開き直してConsoleをClear

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自分のプロジェクトで原因を探すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります。
この症状では：外れた部品の番号から VRCFury が足りないことを当て、入手先を出します。
改変おたすけ診断（無料版あり）
