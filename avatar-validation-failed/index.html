Avatar validation failed が出てアップロードできない（本当の原因の探し方）

まずはこれ
  1. VRChat SDK → Show Control Panel → Builder タブを開き、「2. Review Any Alerts」の赤い項目を読む（黄色は注意だけで、ビルドは止めない）
  2. Console（Window → General → Console）で Clear を押してからもう一度ビルドし、「Encountered the following validation issues during build:」のすぐ下の赤い行を読む

自動で調べたいなら：改変おたすけ診断がアップロードを止めている所を1クリックで見つけます（無料版あり）。無料で試す

画面に出る文字：

Build Failed Your avatar failed to build or upload because of the following reason Avatar validation failed （Console）Encountered the following validation issues during build: （この下に、止めた本当の理由が1行ずつ出る）

意味

VRChat SDK がビルドの途中でアバターを調べ、赤い項目（エラー）が1つ以上あったときに出る、まとめの知らせです。この文自体は理由を言いません。理由は Console の「Encountered the following validation issues during build:」のすぐ下に、赤い行で1つずつ出ます（SDK 3.10.6 で確認）。SDK の画面では「Build Failed」の下にこの文が出て、「Check Console for more details」ボタンで Console が開きます。このチェックは SDK 3.3.0 から、Modular Avatar・VRCFury など、アップロード時に動く道具が処理を終えたあとのアバターに対して行われます。そのため、ふだんの画面では何も赤くないのに、ビルドのときだけ止まることがあります。

よくある原因

  • Expressions のメニューとパラメータの片方だけが入っている（VRCExpressionsMenu / VRCExpressionParameters object reference is missing.）
  • 同期パラメータが多すぎる（VRCExpressionParameters has too many parameters defined.）。道具がビルド中に足した分も、ここで数えられる
  • メニューが、パラメータの一覧に無い名前を使っている（VRCExpressionsMenu uses a parameter that is not defined.）
  • 音・パーティクル・テクスチャの設定（Load In Background がオフの音、止まると自分を消すパーティクル、Streaming Mip Maps がオフのテクスチャなど）
  • PhysBone のつながりが深すぎる（maximum dependency depth）。道具が処理したあとにだけ起きることがある
  • Quest（Android）向けで、VRChat/Mobile 以外のシェーダーを使っている（Avatar uses unsupported shader）
  • Humanoid の骨の割り当てが足りない（Humanoid avatar must have head, hands and feet bones mapped. など）

原因の見分け方

  • ビルドの前から「2. Review Any Alerts」に赤い項目がある
    → その項目が理由。右の Select で問題の物が選ばれ、Auto Fix があれば押すと直る
  • Review Any Alerts は黄色だけ（または何も無い）のに、ビルドすると止まる
    → アップロード時に動く道具が処理したあとのアバターで、赤が出ている。Console の「Encountered the following validation issues during build:」の下を読む
  • Console の赤い行に too many parameters・dependency depth が出る
    → 道具が足したパラメータや PhysBone で上限を超えている。道具を外した複製でビルドすると通るなら、その道具が原因
  • 止まったときの文が「Avatar download size is too large for the target platform」など別の文
    → このページのエラーではない。容量の上限など、その文の原因を探す

直し方

  1. VRChat SDK → Show Control Panel → Builder タブを開き、「2. Review Any Alerts」の赤い項目を読む（黄色は注意だけで、ビルドは止めない）
  2. Console（Window → General → Console）で Clear を押してからもう一度ビルドし、「Encountered the following validation issues during build:」のすぐ下の赤い行を読む
  3. Review Any Alerts の赤い項目の右に Select があれば押して、問題の物を選ぶ。Auto Fix があれば、プロジェクトを複製してから押す
  4. Auto Fix が無い項目は、Console に出た文をこの辞典で探して直す（例：object reference is missing → Expressions の欄、too many parameters → 同期するパラメータを減らす）
  5. Review Any Alerts には出ず、ビルドのときだけ出る項目は、アップロード時に動く道具が足した物が原因。シーンでアバターを複製し、複製から道具の部品を1つずつ外してビルドし、どれで止まるかを確かめる
  6. Console に理由が1行も出ないときは、ALCOM（またはVCC）で VRChat SDK を最新にして、もう一度ビルドする
  7. 赤い行がすべて消えたら、もう一度 Build を押す

よくある勘違い

  • 「Avatar validation failed」の文で検索しても、答えは見つかりにくい。調べるのは、Console でその前に出ている赤い行の文。
  • 黄色い項目（Warning）を全部消さなくてよい。ビルドを止めるのは赤い項目（Error）だけ。
  • 近くに出る「Loaded data for an avatar we do not own, clearing blueprint ID」は黄色の注意（Warning）で、ビルドを止めた理由ではない。
  • 容量オーバーではこの文は出ない。容量のときは「Avatar download size is too large for the target platform」という別の文で、ビルドのあとのアップロードの段階で止まる。
  • 「Security Checks Failed」とは別物。あちらは、アップロードしたあとに VRChat のサーバーで止められたときに出る。

よくある質問

画面に赤い項目が無いのに Avatar validation failed になるのはなぜ？

SDK 3.3.0 から、チェックはアップロード時に動く道具（Modular Avatar・VRCFury など）が処理を終えたあとのアバターに対して行われるからです。道具が足したパラメータで上限を超える、PhysBone のつながりが深くなる、といった問題は、ビルドのときにだけ見つかります。Console の「Encountered the following validation issues during build:」の下に出る文を読んでください。

VPN を切る・ログインし直すと直る？

このエラーは Unity の中のチェックで出るので、通信やログインのやり直しでは消えません。Console に出た赤い行の原因を直す必要があります。

Auto Fix は押していい？

Auto Fix は、SDK が直し方を知っている項目にだけ出るボタンです（Pipeline Manager の追加、Dynamic Bone から PhysBone への変換など）。アバターの中身を書き換えるので、押す前にプロジェクトのフォルダを複製しておくと、元に戻せます。

Quest（Android）用のときだけ失敗する

Android 向けでは、シェーダーは VRChat/Mobile の物しか使えません。Console に「Avatar uses unsupported shader」と出ていれば、それが理由です。Quest 用のマテリアルを VRChat/Mobile のシェーダーに替えてからビルドします。

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。
