Avatar validation failed が出てアップロードできない（本当の原因の探し方）

画面に出る文字：

Avatar validation failed

意味

SDKのチェックでビルドが止められた、という大まかな知らせです。この文自体は理由を言っていません。本当の理由は、SDKの画面の Validations か、Consoleでこの文より前に出ている赤エラーにあります。すぐ後に出る「clearing blueprint ID」は、たいてい気にしなくてよい文です。

よくある原因

  • Validations に赤い項目がある（メニューのパラメータ・Expressions・アイコン・音・テクスチャ・メッシュの設定など）
  • 容量の上限を超えている（PCはダウンロード200MB・展開後500MB、Android（Quest）は10MB・40MB）
  • Quest用のとき、Questで使えないシェーダーなどが入っている
  • アップロード時に動く道具（Modular Avatar・VRCFuryなど）がビルド中にエラーを出した
  • SDKが古い

直し方

  1. VRChat SDK → Show Control Panel → Builder を開き、Validations の赤い項目を全部読む（黄色は注意だけ）
  2. ConsoleでClearを押し、もう一度ビルドして、「Avatar validation failed」より上にある最初の赤エラーを読む
  3. その文をこの辞典で探して直す
  4. ALCOM（またはVCC）でVRChat SDKと道具（Modular Avatar・VRCFuryなど）を最新にする
  5. 何も出ないときは、VPN・WARPを切る／SDKの画面を開き直してログインし直す

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自分のプロジェクトで原因を探すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります。
この症状では：アップロードを止める設定の多くをまとめて調べ、1つずつ日本語で説明します。
改変おたすけ診断（無料版あり）
