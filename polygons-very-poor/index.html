ポリゴン数（Triangles）が多すぎて Very Poor になる・減らし方（PC 7万・Quest 2万）

まずはこれ
  1. SDKの画面（Builder）でランクの内訳を開き、Triangles の数を見る
  2. 重いメッシュを探す：各 Skinned Mesh Renderer の Mesh の欄を押してメッシュの元ファイルを光らせ、それを選ぶと、Inspector の下のプレビューに三角形の数が出る

自動で調べたいなら：Performance Rank DoctorがPC・Questのランクを下げている項目を理由つきで一覧にします（無料版あり）。無料で試す

画面に出る文字：

Triangles: …（SDKの画面・ランクの内訳）

意味

Triangles は、アバターの全部のメッシュの三角形の合計です。VRChatはオフにした物も含めて全部数えるので、隠している着替え用の服も数に入ります。PCの上限は Excellent 3万2千、Good・Medium・Poor はどれも7万で、7万を1つでも超えると Very Poor です。Quest（スマホ）は Excellent 7,500・Good 1万・Medium 1万5千・Poor 2万です。PCは初期設定で Very Poor まで表示されるので見えますが、スマホは初期設定で Medium 以上しか表示されないため、1万5千を超えると多くのスマホの人には見えません（Show Avatar を押せば見えます）。

よくある原因

  • 着替え用の服・小物を、オフにしたまま全部アバターに入れている（オフでも数える）
  • 服の下で見えない所まで、体のメッシュが全部残っている
  • 別に買った髪・アクセサリー・服が、元のアバターよりずっとポリゴンが多い
  • Modular Avatar で服を何着も着せていて、それぞれのメッシュが丸ごと入っている
  • Quest版でもPC版のメッシュをそのまま使っている

直し方

  1. SDKの画面（Builder）でランクの内訳を開き、Triangles の数を見る
  2. 重いメッシュを探す：各 Skinned Mesh Renderer の Mesh の欄を押してメッシュの元ファイルを光らせ、それを選ぶと、Inspector の下のプレビューに三角形の数が出る
  3. 着ない服・小物は、アバターから消すか、アップロードしない別の複製に移す（オフにしても数は減らない）
  4. 服の下に隠れた体のポリゴンを AAO（Avatar Optimizer）で消す：Remove Mesh By BlendShape は体の「縮める」シェイプキーを、Remove Mesh By Mask はマスク画像を使う
  5. まだ重い所は、ポリゴンを減らす道具（Blender の Decimate など）で減らし、顔と手の形・シェイプキーがくずれていないか確かめる
  6. AAO などアップロードの時に動く道具（NDMF）は、ビルドの時にだけメッシュを変えるので、Unityの画面の数字は前のまま出ることがある。上げたあとVRChatで出るランクで確かめる
  7. Quest用は複製して作り、初期設定で見える1万5千以下（Medium）をめざす。数字は変わることがあるので、最新の公式の表（creators.vrchat.com の Avatar Performance Ranking System）も確かめる

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityで「診断する」を押すだけで、PC・Questのランクを下げている項目と、直すと何ランク上がるかを一覧にする道具です（有料版はよくある原因を1クリックで直します）。
この症状では：ポリゴン数かほかの項目か、PC・Questのランクを下げている物と、直すと何ランク上がるかを一覧にします。

関係するエラー

  • アバターが Very Poor / Poor になる（PC・Questの上限の意味と直し方）
  • マテリアル（Material Slots）が多すぎる・Very Poor やQuestで見えない時の減らし方
  • meshes that were imported with Read/Write disabled（メッシュの Read/Write がオフ）
  • 上げたアバターが出てこない・ほかの人には別のアバター（ロボット）に見える
