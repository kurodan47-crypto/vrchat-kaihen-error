particle systems configured to destroy themselves（エフェクトが自分を消す設定）

まずはこれ
  1. Hierarchyでパーティクルの付いた物を選ぶ（エラーの Select ボタンでも選べます）
  2. Inspectorの Particle System の一番上の欄で Stop Action を None か Disable にする

自動で調べたいなら：改変おたすけ診断がこの設定を1クリックで見つけます（無料版あり）。無料で試す

画面に出る文字：

This avatar contains one or more particle systems configured to destroy themselves when they stop. This is not allowed. Please use a different stop action.

意味

パーティクル（光や粒のエフェクト）の Stop Action が Destroy になっています。止まったときに自分を消す設定はVRChatでは使えないので、アップロードできません。アバターのルートに付いたパーティクルが Disable の場合や、トレイル（軌跡）の Autodestruct、持てる物（Pickup）に力を当てる当たり判定も同じように止められます。

よくある原因

  • エモート・ポーズ・エフェクトのギミックを入れた
  • Unityの素材やほかのゲーム用のエフェクトを流用した

直し方

  1. Hierarchyでパーティクルの付いた物を選ぶ（エラーの Select ボタンでも選べます）
  2. Inspectorの Particle System の一番上の欄で Stop Action を None か Disable にする
  3. トレイルなら Trail Renderer の Autodestruct のチェックを外す
  4. Collision を使っているなら Collides With から Pickup・Item のレイヤーを外す

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります（有料版は多くを1クリックで直します）。
この症状では：当てはまるパーティクル・トレイルを一覧にし、有料版なら1クリックで使える設定に直します。
改変おたすけ診断（無料版あり）
