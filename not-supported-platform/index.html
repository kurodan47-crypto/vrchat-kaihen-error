このアバターは今の機種では使えない（PC専用・Quest版が無い）

画面に出る文字：

（このプラットフォームでは使えないと出る／Questのフレンドからはロボットに見える）

意味

PC版とQuest（Android）版は別々に上げる物です。今の機種向けの版が無いアバターは、着られず、ほかの人からは代わりのアバター（ロボットなど）に見えます。

よくある原因

  • PC版だけ上げて、Android版を上げていない
  • Android版を別のBlueprint IDに上げた
  • Android向けに作ったのに、書き出し先がWindowsのまま上げた

直し方

  1. アバターを複製し、Quest用の版を作る（元のPC用は残す）
  2. 書き出し先を Android に切り替える
  3. Questで使えないシェーダー・揺れもの・上限を直す
  4. PC版と同じBlueprint IDに上げる

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自分のプロジェクトで原因を探すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります。
この症状では：書き出し先と、Questで使えないシェーダーを調べます。
改変おたすけ診断（無料版あり）

関係するエラー

  • Avatar uses unsupported shader（Quest版でピンク・アップロードできない）
  • 上げたアバターが出てこない・ほかの人には別のアバター（ロボット）に見える
  • Blueprint ID（アップロード先の番号）の問題
  • Quest版で髪やスカートが揺れない（PhysBoneの上限）
