Blueprint ID（アップロード先の番号）の問題

画面に出る文字：

Blueprint ID … / blueprint

意味

アップロード先の番号が合っていません。

よくある原因

  • 他人のアバターの番号が残っている

直し方

  1. Pipeline Managerの「Detach」を押してから上げ直す

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自分のプロジェクトで原因を探すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります。
この症状では：このエラーが出ていれば、日本語で直し方を出します。
改変おたすけ診断（無料版あり）

関係するエラー

  • Missing Credentials（ログインしているのに認証エラー）
  • All pipe instances are busy
  • アカウントがまだアップロードできない
  • Security Checks Failed が出る（アバターが使えない・アップロードできない）
