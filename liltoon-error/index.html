lilToon関係のエラー・lilToonなのにピンク色

まずはこれ
  1. ALCOM（またはVCC）でlilToonを追加・更新
  2. それでもピンクなら、マテリアルを選びInspectorのShaderを lilToon に選び直す

自動で調べたいなら：改変おたすけ診断がピンクのマテリアルと足りないシェーダーを1クリックで見つけます（無料版あり）。無料で試す

画面に出る文字：

lilToon … / Shader error in 'lilToon'

意味

見た目を決めるシェーダー lilToon が無いか、版が合っていません。

よくある原因

  • lilToonが入っていない
  • 版が古い・新しすぎる
  • 入れ直しの順番で、マテリアルとのつながりが切れた

直し方

  1. ALCOM（またはVCC）でlilToonを追加・更新
  2. それでもピンクなら、マテリアルを選びInspectorのShaderを lilToon に選び直す
  3. アバターの説明書に版の指定があれば合わせる

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります（有料版は多くを1クリックで直します）。
この症状では：ピンク色のマテリアルと、足りないシェーダーの名前を推測します。
改変おたすけ診断（無料版あり）

関係するエラー

  • アバター・衣装がピンク色（マゼンタ）になる
  • Shader error in（シェーダーのエラー）
  • Avatar uses unsupported shader（Quest版でピンク・アップロードできない）
  • Missing Script（外れた部品）
