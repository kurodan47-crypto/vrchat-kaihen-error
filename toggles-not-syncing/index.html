EnglishVRChat改変エラー辞典

トグル（服の着脱など）がほかの人に同期しない

画面に出る文字：

（エラー文は出ず、自分の画面では切り替わるのに、ほかの人には変わって見えない）

意味

メニューの切り替えをほかの人に送るのは、Expression Parameters で「Synced」がオンのパラメータだけです。オフのまま、または一覧に入っていないパラメータは、自分の画面でしか変わりません。

よくある原因

  • Expression Parameters でそのパラメータの「Synced」がオフ
  • アニメーターだけで使っていて、Expression Parameters に登録していない
  • パラメータの名前の大文字・小文字がメニューとアニメーターでちがう
  • IsLocal を使った「自分にだけ見せる」作りになっている
  • 相手がアバターを隠している・安全設定でアニメーションを止めている

直し方

  1. Avatar Descriptor → Expressions → Parameters を開き、そのパラメータの「Synced」にチェックを入れる
  2. メニュー・アニメーター・パラメータで名前が完全に同じか確かめる
  3. 同期の合計が256bitを超えないか確かめる（bool=1bit、int・float=8bit）
  4. 上げ直してから、フレンドに見てもらう

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自分のプロジェクトで原因を探すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります。
この症状では：同期パラメータの使用量を256bitで数え、登録されていないパラメータを使うメニュー項目を一覧にします。
改変おたすけ診断（無料版あり）

関係するエラー

  • トグルの状態が保存されない（着替えるたびに戻る）
  • 同期パラメータが256bitを超えている
  • uses a parameter that is not defined（メニューのパラメータ）
  • ハンドジェスチャーで表情が変わらない・手の形が動かない
