Modular Avatar（nadena.dev）関係のエラー

画面に出る文字：

nadena.dev.modular_avatar … / ModularAvatar …

意味

Modular Avatar（衣装の着せ替えやギミックの多くが前提にしている部品）が無い・版が合わない状態です。

よくある原因

  • Modular Avatarが入っていない
  • 衣装・ギミックが求める版より古い（または新しすぎる）

直し方

  1. ALCOMでModular Avatarを追加・最新に更新
  2. 説明書に版の指定があれば、それに合わせる
  3. Unityを開き直してConsoleをClear

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自分のプロジェクトで原因を探すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります。
この症状では：Modular Avatarが入っているかを調べます。
改変おたすけ診断（無料版あり）
