意味

VRChatは、アバターの足元（オブジェクトの原点）と目の高さ（View Position）を基準に、体を地面に合わせます。この基準がずれていると、アバターが浮いて見えます。

よくある原因

  • アバターのオブジェクトが (0, 0, 0) にない、または傾いている
  • View Position が目より高い・前にある（頭が大きいアバターは、上下を向くと足が浮くことがあります）
  • モデルを読み込んだとき、足元が原点より上にずれている
  • Humanoid の設定で Hips などに別の骨が割り当てられている
  • 自分で入れたアニメーション（Base・Action）が体の位置を動かしている

直し方

  1. Hierarchyでアバターを選び、Transform の Position・Rotation を 0 にする（Scale は変えない）
  2. Avatar Descriptor の View Position を、目と目のあいだに置き直す
  3. シーンで横から見て、靴の裏が地面（Y=0）に乗っているか確かめる
  4. モデルの Rig → Configure を開き、Hips・脚の骨が正しいか確かめる
  5. 最近入れたギミックを外したテスト用の複製を上げ、直るか試す

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityで「診断する」を押すだけで、靴底と地面のずれ・目線（View Position）のずれをcmで測り、ルートやリグも調べる道具です（有料版はまとめて1クリックで直します）。
この症状では：Humanoid の設定とAvatar Descriptorがそろっているかを調べます（View Positionの位置や足の高さは測りません）。

  • 非対応衣装が体についてこない（ボーン名のちがい）
