同期パラメータが256bitを超えている

まずはこれ
  1. 使っていないギミックを外す
  2. 同期しなくてよいものは同期をオフにする（bool=1bit、int/float=8bit）

自動で調べたいなら：改変おたすけ診断がこの設定を1クリックで見つけます（無料版あり）。無料で試す

画面に出る文字：

Too many synced parameters / exceeds the maximum (256 bits)

意味

同期パラメータの合計が上限の256bitを超えています。ギミックを入れすぎると起きます。

よくある原因

  • ギミック・衣装のトグルが多い
  • Modular Avatarが足すパラメータも合計に入る

直し方

  1. 使っていないギミックを外す
  2. 同期しなくてよいものは同期をオフにする（bool=1bit、int/float=8bit）

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります（有料版は多くを1クリックで直します）。
この症状では：使用量を「○○ / 256 bit」で数え、Modular Avatarが足す分も数えます。
改変おたすけ診断（無料版あり）
