同期パラメータが256bitを超えている

まずはこれ
  1. 使っていないギミックを外す
  2. 同期しなくてよいものは同期をオフにする（bool=1bit、int/float=8bit）

自動で調べたいなら：Parameter Bit Saverがbitを多く使っているパラメータを並べ、同期しなくていい物を見つけます（無料版あり）。無料で試す

画面に出る文字：

Too many synced parameters / exceeds the maximum (256 bits)

意味

同期パラメータの合計が上限の256bitを超えています。ギミックを入れすぎると起きます。

よくある原因

  • ギミック・衣装のトグルが多い
  • Modular Avatarが足すパラメータも合計に入る

直し方

  1. 使っていないギミックを外す
  2. 同期しなくてよいものは同期をオフにする（bool=1bit、int/float=8bit）

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityの窓に、同期パラメータをbitの多い順に並べ、同期しなくていい物を見つける道具です（有料版はそれらの同期を1クリックで外します。Ctrl+Zで戻せます）。
この症状では：使用量を「○○ / 256 bit」で数え、Modular Avatarが足す分も数えます。
Parameter Bit Saver（無料版あり）

無料版はVCCで入れられる：https://kurodan47-crypto.github.io/kaihen-vpm/

ほかにも困っているなら：6本セット 1,980円（単品合計4,500円）＝ピンク・めり込み・浮く・ランク・QuestのPhysBone・パラメータ

  • Images used for Actions & Moods are too large（メニューのアイコンが大きすぎる）
