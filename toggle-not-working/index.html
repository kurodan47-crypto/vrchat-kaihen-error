画面に出る文字：

（エラー文は出ず、アクションメニューのトグルを押しても、自分の画面でも何も変わらない）

意味

メニューのトグルは、①メニューの項目、②Expression Parameters の同じ名前のパラメータ、③FXのアニメーターの同じ名前のパラメータ、④正しい物を指すアニメ、の4つがつながって初めて動きます。どこか1つが切れていると、エラーも出ずに何も起きません。自分の画面では変わるのに、ほかの人に見えないときは同期の問題です（「トグルがほかの人に同期しない」のページ）。

よくある原因

  • メニュー・Expression Parameters・アニメーターで、パラメータの名前がちがう（大文字・小文字や、最後の空白もちがいになる）
  • アニメを作ったあとに物の名前を変えた・場所を動かしたので、アニメが無い場所を指している（Animation ウィンドウで黄色く「Missing!」と出る）
  • トグルのレイヤーを FX でなく Gesture や Base のアニメーターに入れた（物のオン・オフやシェイプキーは FX に入れる）
  • FX のレイヤーの重み（Weight）が0のまま
  • 遷移の条件がちがう：別のパラメータ・true と false が逆・Has Exit Time がオンのまま
  • 下にある FX のレイヤーが同じ物やシェイプキーを書いていて、そちらが勝っている
  • Write Defaults がステートによってオンとオフで混ざっている
  • Int のパラメータで、メニューの Value が遷移の条件の数字と合っていない

直し方

  1. まずUnityで試す：Gesture Manager か Av3Emulator を入れて再生し、トグルを押して、パラメータとアニメーターのステートが変わるかを見る
  2. メニュー項目の Parameter・Expression Parameters・FX のアニメーターの Parameters タブの名前が、完全に同じか見比べる
  3. そのレイヤーが Avatar Descriptor の FX に入っているアニメーターの中にあり、Weight が1か確かめる
  4. 遷移を見る：パラメータが true（または Int の数字）でオンのステートへ、false でオフのステートへ行き、Has Exit Time はオフ
  5. オンとオフのアニメを Animation ウィンドウで開き、「Missing!」の項目があれば、物の名前・場所を元に戻すか、アニメを録り直す
  6. Write Defaults を全部のステートでそろえる（Write Defaults が混ざっているページを参照）
  7. 上げ直して、VRChatで確かめる

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。
