VRChat改変エラー辞典

Dynamic Bone（古い揺れもの）が残っている

まずはこれ
  1. VRChat SDKの変換機能などでPhysBoneに置き換える
  2. 使わない物は外す

自動で調べたいなら：改変おたすけ診断が赤エラーの説明と足りない道具を1クリックで出します（無料版あり）。無料で試す

画面に出る文字：

DynamicBone … could not be found

意味

古い揺れもの（Dynamic Bone）は今のVRChatでは使われず、PhysBoneに置き換わっています。

よくある原因

  • 古いアバター・衣装に残っていた

直し方

  1. VRChat SDKの変換機能などでPhysBoneに置き換える
  2. 使わない物は外す

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります（有料版は多くを1クリックで直します）。
この症状では：古い揺れものが残っていないかを調べます。
改変おたすけ診断（無料版あり）

関係するエラー

  • Quest版で髪やスカートが揺れない（PhysBoneの上限）
  • All compiler errors have to be fixed before you can enter playmode
  • Missing Script（外れた部品）
  • The type or namespace name 'VRC' could not be found
