マテリアル（Material Slots）が多すぎる・Very Poor やQuestで見えない時の減らし方

まずはこれ
  1. SDKの画面（Builder）でランクの内訳を開き、Material Slots の数を見る
  2. Mesh Renderer / Skinned Mesh Renderer の Materials の数が、メッシュの部品の数より多ければ、余った枠を消す（見た目は変わらない）

自動で調べたいなら：Performance Rank Doctorが余ったマテリアル枠を見つけ、PC・Questのランクの見込みを出します（無料版あり）。無料で試す

画面に出る文字：

Material Slots: …（SDKのパフォーマンス表示・ランクの内訳）

意味

マテリアルの枠1つごとに、表示の命令（ドローコール）が1回増えます。PCは Excellent 4・Good 8・Medium 16・Poor 32まで、Quest（スマホ）は Excellent 1・Good 1・Medium 2・Poor 4までで、超えるとランクが下がります。Questは初期設定でMedium以上しか表示されないので、マテリアルが3つ以上あると多くの人に見えません。オフにしている服や小物の枠も数に入ります。

よくある原因

  • 着替え用の服・小物を、オフにしたまま全部アバターに入れている
  • 服・髪・アクセサリーがそれぞれ別のマテリアルを使っている
  • メッシュの部品（サブメッシュ）の数より多くマテリアルを入れている（余った枠は最後の部品をもう一度描くだけで、ムダに重くなる）
  • Quest版でもPC版と同じマテリアルの数のまま

直し方

  1. SDKの画面（Builder）でランクの内訳を開き、Material Slots の数を見る
  2. Mesh Renderer / Skinned Mesh Renderer の Materials の数が、メッシュの部品の数より多ければ、余った枠を消す（見た目は変わらない）
  3. 着ない服・小物は、アバターから消すか、アップロードしない別の複製に移す
  4. 同じマテリアルを使う部品は、AAO（Avatar Optimizer）の Merge Skinned Mesh などで1つにまとめる
  5. テクスチャを1枚にまとめる（アトラス化）道具やBlenderで、複数の部品が1つのマテリアルを使えるようにする
  6. Quest用は複製して、マテリアル2つ以下（Medium）をめざす。衣装に「1マテリアル版」があればそれを使う

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityで「診断する」を押すだけで、PC・Questのランクを下げている項目と、直すと何ランク上がるかを一覧にする道具です（有料版はよくある原因を1クリックで直します）。
この症状では：マテリアルの数とPC・Questのランクの見込みを出し、余った枠のある所を一覧にします。有料版なら余った枠を1クリックで消します（Ctrl+Zで戻せる）。
Performance Rank Doctor（無料版あり）

関係するエラー

  • アバターが Very Poor / Poor になる（PC・Questの上限の意味と直し方）
  • テクスチャのメモリ（Texture Memory）が多すぎる・減らし方
  • Avatar uses unsupported shader（Quest版でピンク・アップロードできない）
  • 上げたアバターが出てこない・ほかの人には別のアバター（ロボット）に見える
