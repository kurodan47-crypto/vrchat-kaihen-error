アバターが Very Poor / Poor になる（PC・Questの上限の意味と直し方）

まずはこれ
  1. SDKの画面（Builder）でランクの内訳を見て、一番悪い項目を探す
  2. テクスチャはMax Sizeを下げ、圧縮をかける（テクスチャのメモリのページを参照）

自動で調べたいなら：Performance Rank DoctorがPC・Questのランクを下げている項目を理由つきで一覧にします（無料版あり）。無料で試す

画面に出る文字：

Performance Rank: Very Poor / Poor（SDKの画面・VRChatのアバター情報）

意味

パフォーマンスランクは、項目ごとの数字で一番悪い物に合わせて決まります。1つでもPoorの上限を超えるとVery Poorです。PCは初期設定でVery Poorまで表示されますが、Quest（スマホ）は初期設定でMedium以上しか表示されず、Very Poorは設定でも表示にできません（Show Avatarを押せば見えます）。さらにQuestで PhysBone・Contact・Constraint がVery Poorになると、それらは全部外されます。

よくある原因

  • ポリゴン数：PCはGood以上で7万まで（Excellent 3.2万）、Questは Poor で2万まで
  • テクスチャのメモリ：PCは Poor 150MB・Medium 110MB・Good 75MB、Questは Poor 40MB・Good 18MB
  • メッシュの数：Skinned Mesh はPC Poor 16・Questは 2まで、マテリアルの数はPC Poor 32・Quest Poor 4
  • ボーン：PC Poor 400・Quest Poor 150
  • PhysBone：PC Poor 32個・動く骨256、Quest Poor 8個・動く骨64
  • パーティクル・ライト・Cloth など（Questではライト・Cloth・音などは使えず0扱い）

直し方

  1. SDKの画面（Builder）でランクの内訳を見て、一番悪い項目を探す
  2. テクスチャはMax Sizeを下げ、圧縮をかける（テクスチャのメモリのページを参照）
  3. 使っていない服・小物のメッシュを消し、AAOなどでメッシュ・マテリアルをまとめる
  4. PhysBoneは残す鎖を選んで減らす
  5. Quest用は複製して作り、Medium以上（できればGood）をめざす
  6. 数字は変わることがあるので、最新の公式の表（creators.vrchat.com の Avatar Performance Ranking System）も確かめる

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

関係するエラー

  • テクスチャのメモリ（Texture Memory）が多すぎる・減らし方
  • Quest版で髪やスカートが揺れない（PhysBoneの上限）
  • Avatar uses unsupported shader（Quest版でピンク・アップロードできない）
  • 上げたアバターが出てこない・ほかの人には別のアバター（ロボット）に見える
  • meshes that were imported with Read/Write disabled（メッシュの Read/Write がオフ）
