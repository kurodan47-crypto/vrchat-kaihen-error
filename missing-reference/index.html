Inspectorの欄が「Missing」になっている

画面に出る文字：

Missing (Transform) / Missing (Material) など

意味

欄が指していたファイルやオブジェクトが消えて、つながりが切れています。Noneとはちがい、元は何かが入っていた印です。

よくある原因

  • 衣装のボーンや部品を消した
  • 元のファイルを消した・入れ直した

直し方

  1. 対象を選び、Inspectorで「Missing」の欄を探す
  2. 正しい物を入れ直す
  3. 消したボーンが原因なら、元のunitypackageを入れ直す

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自分のプロジェクトで原因を探すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります。
この症状では：つながりが切れた欄がある部品を一覧にします。
改変おたすけ診断（無料版あり）
