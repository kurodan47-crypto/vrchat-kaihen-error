Missing Script（外れた部品）

画面に出る文字：

The referenced script on this Behaviour is missing! / Missing (Mono Script)

意味

部品を作ったツールが入っていないか、版が合っていません。アップロードを止める原因になります。

よくある原因

  • Modular Avatar・VRCFuryなど、衣装が前提にしているツールの入れ忘れ
  • 版ちがい

直し方

  1. 説明書の「必要なもの」を全部入れる
  2. どのツールが足りないか分からないときは、外れた部品に残っている番号（GUID）から当てられます。診断ツールは Modular Avatar・VRCFury・AAO・lilycalInventory・FaceEmo・lilToon・Poiyomi・VRChat SDK を名指しして入手先を出します
  3. それでも残る物は、不要なら外す（Remove Missing Script）

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自分のプロジェクトで原因を探すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります。
この症状では：外れた部品のある物を一覧にし、どのツールが足りないかと入手先を出します。有料版なら1クリックで外します。
改変おたすけ診断（無料版あり）

関係するエラー

  • VRCFury が入っていない（VRCFury関係のMissing Script・エラー）
  • FaceEmo が入っていない（表情メニューのMissing Script）
  • Modular Avatar（nadena.dev）関係のエラー
  • The type or namespace name 'VRC' could not be found
