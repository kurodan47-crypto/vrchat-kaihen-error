自動で調べたいなら：Light & Bounds Fixerが消えることがあるメッシュと、光の基準がそろっていないメッシュを一覧にします（無料版あり）。無料で試す

画面に出る文字：

（エラー文は出ず、ワールドによって体・服・髪の明るさや色がちがって見える）

意味

メッシュは、ワールドの光（ライトプローブ・リフレクションプローブ）を1つの点で受け取ります。何も決めていないと、その点はメッシュごとの Bounds の中心になるので、体・服・髪が別々の場所の光を受けて、明るさがちがって見えます。Anchor Override は、その点を自分で決める欄です。全部のメッシュを同じ点にすれば、同じ明るさになります。

よくある原因

  • Anchor Override が空のメッシュがある、またはメッシュごとに別のボーンを指している
  • あとから着せた服のメッシュだけ、設定がちがう
  • メッシュごとに Bounds と Root Bone がちがい、光を受ける点が離れている
  • マテリアルのシェーダーや光の設定がちがう（例：lilToon の明るさの上限・下限）。これは Anchor Override では直らない

直し方

  1. 基準にするボーンを1つ決める（Chest か Hips が多い）
  2. アバターの Skinned Mesh Renderer と Mesh Renderer を全部選び（まとめて選べる）、Probes の中の Anchor Override にそのボーンを入れる
  3. Modular Avatar を使っているなら、アバターのルートに MA Mesh Settings を付けて Anchor Override を決める（「衣装をセットアップ」で着せた服はそれに従う）
  4. それでも明るさがちがう時は、体と服のマテリアルのシェーダーの光の設定を見比べる
  5. アップロードして、光の差が大きいワールド（色つきの照明がある室内など）で確かめる

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。
