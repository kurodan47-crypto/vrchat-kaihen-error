VRChat改変エラー辞典

アバターや衣装をUnityに入れたときの「ピンク色になった」「赤エラーが消えない」「アップロードできない」を、意味・原因・直し方の順に日本語でまとめました。（全31件）

  • Security Checks Failed が出てアップロードできない
  • All compiler errors have to be fixed before you can enter playmode
  • The type or namespace name 'VRC' could not be found
  • Modular Avatar（nadena.dev）関係のエラー
  • lilToon関係のエラー・lilToonなのにピンク色
  • アバター・衣装がピンク色（マゼンタ）になる
  • Missing Prefab（ヒエラルキーで名前が赤い）
  • Inspectorの欄が「Missing」になっている
  • 他人のアバターの番号が残っている（avatar we do not own）
  • Avatar Failed Upload / Failed to upload
  • Missing Credentials（ログインしているのに認証エラー）
  • All pipe instances are busy
  • uses a parameter that is not defined（メニューのパラメータ）
  • 同期パラメータが256bitを超えている
  • フォルダの場所（パス）の問題：日本語・長すぎるパス
  • 部品（パッケージ）が読み込めない（Failed to resolve packages）
  • Missing Script（外れた部品）
  • Dynamic Bone（古い揺れもの）が残っている
  • Shader error in（シェーダーのエラー）
  • アカウントがまだアップロードできない
  • Blueprint ID（アップロード先の番号）の問題
  • NullReferenceException（空の参照）
  • 非対応衣装が体についてこない（ボーン名のちがい）
  • VRCExpressionsMenu / VRCExpressionParameters object reference is missing
  • Gesture Layer needs valid mask on first animator layer（手のマスクが無い）
  • Images used for Actions & Moods are too large（メニューのアイコンが大きすぎる）
  • Load In Background が有効になっていない音がある
  • This avatar has mipmapped textures without 'Streaming Mip Maps' enabled
  • particle systems configured to destroy themselves（エフェクトが自分を消す設定）
  • meshes that were imported with Read/Write disabled（メッシュの Read/Write がオフ）
  • Blendshape Normals set to 'Calculate' but aren't using 'Legacy Blendshape Normals'
自分のプロジェクトで原因を探すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります。
この症状では：上のエラーをまとめて探し、どこを直すかを一覧にします。
