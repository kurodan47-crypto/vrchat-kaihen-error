Bounds が Very Poor になる・箱（Bounds）が大きすぎる時の原因の探し方と直し方

まずはこれ
  1. SDKの画面（Builder）でランクの内訳を開き、Bounds Size を見る
  2. Skinned Mesh Renderer を1つずつ選び、Bounds（Center / Extent）を見る。Extent は半分の大きさ（Extent が3なら6mの箱）

自動で調べたいなら：Light & Bounds Fixerが箱（Bounds）を広げている物を、SDKと同じ数字で大きい順に出します（無料版あり）。無料で試す

画面に出る文字：

Bounds Size: …（SDKのパフォーマンス表示・ランクの内訳）

意味

Bounds Size は、アバターの全部の表示物（Renderer）が入る箱の大きさです。PCもQuestも同じ上限で、Excellent は 2.5×2.5×2.5m、Good は 4×4×4m、Medium と Poor は 5×6×5mまで、それより大きいと Very Poor です。箱が大きい・遠くにあるメッシュやパーティクルが1つあるだけで全体が Very Poor になりますが、SDKは合計しか出さず、どの物が原因かは教えてくれません。なお Bounds だけが理由でアバターが非表示にされることはありません（全体のランクの表示は下がります）。

よくある原因

  • Skinned Mesh Renderer の Bounds が大きすぎる（消えないように、最初からとても大きい箱にしてある服がある）
  • 体から遠い所に物がある：ワールド固定のギミック、何mも先に置いた小物、消し忘れの物
  • 広く広がるパーティクル（トレイルとラインは Bounds に数えられない）
  • アバター自体が大きい（大きな羽・しっぽ・小道具）
  • アバターや服の大きさ（Scale）を変えて、箱も一緒に大きくなった

直し方

  1. SDKの画面（Builder）でランクの内訳を開き、Bounds Size を見る
  2. Skinned Mesh Renderer を1つずつ選び、Bounds（Center / Extent）を見る。Extent は半分の大きさ（Extent が3なら6mの箱）
  3. Skinned Mesh Renderer の Edit Bounds を押し、腕を上げてもメッシュが入るぎりぎりまで箱を小さくする
  4. Hierarchy で体から遠くにある物を探し、近づけるか消す
  5. Modular Avatar で着せた服は、MA Mesh Settings で箱を決める（アップロードの時はこちらが優先される）
  6. ビルドし直して Bounds Size を見直す

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityの窓に、SDKと同じ計算の Bounds のランク・箱を広げている物の順位・消えることがあるメッシュ・光の基準がそろっていないメッシュを一覧で出す道具です（有料版は光の基準と箱を1クリックでそろえます）。
この症状では：SDKと同じ計算で Bounds のランクを出し、箱を広げている物を大きい順に並べます。有料版なら体の近くのメッシュを1クリックで共通の箱に縮めます（Ctrl+Zで戻せる）。

  • アバターが近づくと消える・服や髪が近くで消える時の直し方（Bounds）

  • 体と服の明るさがちがう・Anchor Override の設定（そろえ方）
  • マテリアル（Material Slots）が多すぎる・Very Poor やQuestで見えない時の減らし方
