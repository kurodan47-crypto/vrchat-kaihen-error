ハンドジェスチャーで表情が変わらない・手の形が動かない

まずはこれ
  1. Avatar Descriptor の Playable Layers で、Gesture と FX に正しいアニメーターが入っているか確かめる
  2. Gesture の1段目の Mask に vrc_HandsOnly を入れる

自動で調べたいなら：改変おたすけ診断がパラメータとアニメーターのレイヤーを1クリックで調べます（無料版あり）。無料で試す

画面に出る文字：

（エラー文は出ず、手の形を変えても表情や手が動かない）

意味

手の形（GestureLeft・GestureRight：0〜7）に合わせて表情や手を動かすのは、Gesture レイヤーと FX レイヤーのアニメーターです。どちらかが外れていたり、設定が欠けていたりすると動きません。

よくある原因

  • Gesture のアニメーターを差し替えたとき、1段目に手のマスク（vrc_HandsOnly）が無い
  • FX のレイヤーの重み（Weight）が 0 のまま
  • 表情のギミックの入れ替えで、FX の欄が別の物になった
  • Write Defaults のオン・オフが混ざっている
  • VRChatのアクションメニューでジェスチャーをオフにしている

直し方

  1. Avatar Descriptor の Playable Layers で、Gesture と FX に正しいアニメーターが入っているか確かめる
  2. Gesture の1段目の Mask に vrc_HandsOnly を入れる
  3. FX の動かないレイヤーの Weight を 1 にする
  4. Write Defaults をどちらかにそろえる
  5. VRChatのアクションメニューの設定で、ジェスチャーがオンか確かめる

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります（有料版は多くを1クリックで直します）。
この症状では：Gesture の1段目のマスク、重みが0のFXレイヤー、Write Defaults の混ざりを調べます。
改変おたすけ診断（無料版あり）

関係するエラー

  • Gesture Layer needs valid mask on first animator layer（手のマスクが無い）
  • FXレイヤーの重みが0で、表情・ギミックが動かない
  • 指が動かない（グーやピースにならない）
  • This avatar uses a mixture of Write Defaults（表情やギミックが戻らない）
