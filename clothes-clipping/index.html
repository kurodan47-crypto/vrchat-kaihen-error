服から体が突き抜ける・めり込む（非対応衣装の貫通）

まずはこれ
  1. アバターの体型シェイプキーを変えたなら、服にある同じ名前のシェイプキーも同じ値にする（Modular Avatar の Blendshape Sync を使うと体に合わせて動く）
  2. 服やアバターに「服の下の体を縮める・隠す」シェイプキーがあれば使う（説明書を見る）

自動で調べたいなら：めり込みチェッカーが服から体が出ている所を1クリックで見つけます（無料版あり）。無料で試す

画面に出る文字：

（エラー文は出ず、胸・お腹・ひじなどの肌が服から見える）

意味

体（素体）の面が、上に着せた服の面より外に出ている状態です。Unityはエラーを出さないので、どこがめり込んでいるかは目で探すしかありません。立ち姿で直しても、しゃがむ・腕を上げると出てくることがあります。

よくある原因

  • その衣装がアバターに対応していない（別のアバター用の服を着せた）
  • アバターの体型のシェイプキー（胸の大きさ・太さなど）を変えたが、服のほうは変えていない
  • 服のボーンが体のボーンと合っていない・大きさ（Scale）を変えた
  • 服が体にぴったりで、離れて見ると肌と服がちらつく

直し方

  1. アバターの体型シェイプキーを変えたなら、服にある同じ名前のシェイプキーも同じ値にする（Modular Avatar の Blendshape Sync を使うと体に合わせて動く）
  2. 服やアバターに「服の下の体を縮める・隠す」シェイプキーがあれば使う（説明書を見る）
  3. 服で隠れる体の所は、AAO（Avatar Optimizer）の Remove Mesh By Mask などで、アップロードの時だけ消す（元のメッシュは変わらない）
  4. 服のボーンを Modular Avatar の Setup Outfit で体につなぎ直す
  5. Playモードやポーズを変えて、腕を上げた・しゃがんだ時も見る
  6. それでも出る所は、Blenderで服を少し外へ広げる

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityで「めり込みを調べる」を押すだけで、服から体が出ている所を赤い点で表示し、服ごとの件数を出す道具です（有料版はその所だけをアップロードの時に隠すAAOの設定を1クリックで作ります）。
この症状では：めり込んでいる所を赤い点で見つけ、有料版ならその所だけを隠すAAOの設定を1クリックで作ります。
