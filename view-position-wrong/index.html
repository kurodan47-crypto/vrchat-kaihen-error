EnglishVRChat改変エラー辞典

目線（カメラの位置）がずれる・体の中から見える

画面に出る文字：

（エラー文は出ず、VRChatで目線が高すぎる・低すぎる・顔の中から見える）

意味

VRChatでのカメラの位置は、Avatar Descriptor の View Position で決まります。ここが目の位置からずれていると、目線が合わず、鏡やほかの人との距離感もおかしくなります。

よくある原因

  • View Position を初期値のまま変えていない
  • アバターの大きさを変えたのに、View Position を直していない
  • View Position が顔の奥（頭の中）や前に出すぎている

直し方

  1. アバターを選び、Inspectorの Avatar Descriptor → View → Edit を押す
  2. 出てきた丸を、目と目のあいだ（横から見て目の少し前）に動かす
  3. 頭が大きいアバターは、ふつうの大きさの頭の目の位置に近づける
  4. Return を押してから、もう一度アップロード

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自分のプロジェクトで原因を探すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります。
この症状では：Avatar Descriptor がそろっているかを調べます（View Positionの位置は測りません）。
改変おたすけ診断（無料版あり）

関係するエラー

  • アップロードしたらアバターが浮いている
  • 足が地面につかない・床にめり込む
  • 指が動かない（グーやピースにならない）
  • 非対応衣装が体についてこない（ボーン名のちがい）
