Quest版で髪やスカートが揺れない（PhysBoneの上限）

まずはこれ
  1. Androidに切り替えてビルドし、SDKのパフォーマンス表示でPhysBoneの数を見る
  2. 残す鎖を決める（多くは髪→耳・しっぽ→スカートの順）。残さない物はQuest用の複製からだけ外す

自動で調べたいなら：Quest PhysBone KeeperがQuestの上限に入る「残すPhysBone」の案を出します（無料版あり）。無料で試す

画面に出る文字：

（エラー文は出ず、Quest・Androidで髪・耳・しっぽ・スカートが揺れない）

意味

Quest（Android）版のアバターにはPhysBoneの上限があります。どれか1つでも超える（Very Poor）と、超えた分だけでなく、PhysBone・Contact・VRChat Constraint が全部外されます。Show Avatar を押してもらっても戻りません。上限はPhysBone 8個・動く骨（affected transforms）64・コライダー16・当たり判定の数（collision checks）64・Contact 16 です。

よくある原因

  • PC用のPhysBoneをそのままAndroid版に残した
  • 衣装や小物がそれぞれPhysBoneを足した
  • 髪の房やスカートの鎖が長く、動く骨が64を超えた

直し方

  1. Androidに切り替えてビルドし、SDKのパフォーマンス表示でPhysBoneの数を見る
  2. 残す鎖を決める（多くは髪→耳・しっぽ→スカートの順）。残さない物はQuest用の複製からだけ外す
  3. 小さい鎖は1つのPhysBoneにまとめ、Ignore Transforms などで動く骨を減らす
  4. 要らないコライダー・Contactを外す
  5. もう一度ビルドし、PhysBoneの行がすべて上限内か確かめる
  6. PC用のアバターは変えず、複製したQuest用で作業する

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityで「診断する」を押すだけで、Questの上限に入るように残すPhysBoneの案（髪・スカートから）を出す道具です（有料版はQuest用の複製を1クリックで作ります）。
この症状では：QuestのPhysBoneの数はまだ数えませんが、Questで使えないシェーダーや外れた部品など、Quest版が壊れるほかの原因を調べます。
Quest PhysBone Keeper（無料版あり）

関係するエラー

  • アバターが Very Poor / Poor になる（PC・Questの上限の意味と直し方）
  • Avatar uses unsupported shader（Quest版でピンク・アップロードできない）
  • 上げたアバターが出てこない・ほかの人には別のアバター（ロボット）に見える
  • Dynamic Bone（古い揺れもの）が残っている
