フォルダの場所（パス）の問題：日本語・長すぎるパス

まずはこれ
  1. プロジェクトを短い英数字だけのフォルダ（例：C:\VRC\Avatar1）へ移す
  2. ALCOM/VCCに登録し直して開く

自動で調べたいなら：改変おたすけ診断が赤エラーの説明と足りない道具を1クリックで出します（無料版あり）。無料で試す

画面に出る文字：

Illegal characters in path / PathTooLongException / DirectoryNotFoundException

意味

プロジェクトの場所に日本語や記号が入っている、またはパスが長すぎます。

よくある原因

  • デスクトップや日本語名のフォルダにプロジェクトを作った
  • フォルダが深すぎる

直し方

  1. プロジェクトを短い英数字だけのフォルダ（例：C:\VRC\Avatar1）へ移す
  2. ALCOM/VCCに登録し直して開く

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります（有料版は多くを1クリックで直します）。
この症状では：プロジェクトの場所を調べます。
改変おたすけ診断（無料版あり）
