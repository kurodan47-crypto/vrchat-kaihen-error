EnglishVRChat改変エラー辞典

The type or namespace name 'VRC' could not be found

画面に出る文字：

error CS0246: The type or namespace name 'VRC' could not be found

意味

VRChat SDKが見つからない、または読み込めていません。

よくある原因

  • VRChat SDK - Avatars が入っていない
  • ALCOM/VCCを使わずにプロジェクトを作った
  • SDKの読み込み中に別のエラーで止まっている

直し方

  1. ALCOM（またはVCC）でこのプロジェクトを選ぶ
  2. 「VRChat SDK - Avatars」を追加（入っていれば最新に更新）
  3. Unityを開き直す

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自分のプロジェクトで原因を探すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります。
この症状では：SDKが入っているかを調べます。
改変おたすけ診断（無料版あり）
