Blendshape Normals set to 'Calculate' but aren't using 'Legacy Blendshape Normals'

画面に出る文字：

This avatar contains skinned meshes that were imported with Blendshape Normals set to 'Calculate' but aren't using 'Legacy Blendshape Normals'.

意味

モデルの読み込み設定で Blendshape Normals が Calculate なのに、Legacy Blendshape Normals がオフになっています。アバターが重くなるため、VRChatはアップロードを止めます。

よくある原因

  • 新しい服・小物のモデルを入れた
  • モデルの読み込み設定を変えた

直し方

  1. Projectでモデルのファイル（.fbx）を選ぶ
  2. Inspectorの Model タブで、Blendshape Normals の下にある「Legacy Blendshape Normals」にチェックを入れる（無ければ Blendshape Normals を Import か None にする）
  3. Apply を押してからもう一度アップロード

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自分のプロジェクトで原因を探すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります。
この症状では：当てはまるモデルを一覧にし、有料版なら1クリックで直します。
改変おたすけ診断（無料版あり）

関係するエラー

  • particle systems configured to destroy themselves（エフェクトが自分を消す設定）
  • uses a parameter that is not defined（メニューのパラメータ）
  • 同期パラメータが256bitを超えている
  • VRCExpressionsMenu / VRCExpressionParameters object reference is missing
