トグルの状態が保存されない（着替えるたびに戻る）

まずはこれ
  1. Avatar Descriptor → Expressions → Parameters を開き、そのパラメータの「Saved」にチェックを入れる
  2. Default を、着たときに一番使う状態に合わせる

自動で調べたいなら：改変おたすけ診断がパラメータとアニメーターのレイヤーを1クリックで調べます（無料版あり）。無料で試す

画面に出る文字：

（エラー文は出ず、アバターを着直すとトグルが元に戻る）

意味

パラメータは、Expression Parameters で「Saved」がオンでないと、アバターを読み込むたびに Default の値に戻ります。

よくある原因

  • Expression Parameters でそのパラメータの「Saved」がオフ
  • Default の値が、ふだん使いたい状態と逆になっている
  • アバターをリセットした（Default に戻る）

直し方

  1. Avatar Descriptor → Expressions → Parameters を開き、そのパラメータの「Saved」にチェックを入れる
  2. Default を、着たときに一番使う状態に合わせる
  3. 上げ直してから、一度切り替えて着直し、残っているか確かめる

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります（有料版は多くを1クリックで直します）。
この症状では：同期パラメータの使用量と、登録されていないパラメータを調べます（Saved のオン・オフは調べません）。
改変おたすけ診断（無料版あり）

関係するエラー

  • トグル（服の着脱など）がほかの人に同期しない
  • 同期パラメータが256bitを超えている
  • ハンドジェスチャーで表情が変わらない・手の形が動かない
  • 表情を出すと口パクが動かない
