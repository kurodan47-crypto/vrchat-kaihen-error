VRChat改変エラー辞典

Avatar uses unsupported shader（Quest版でピンク・アップロードできない）

まずはこれ
  1. アバターを複製して、Quest用はそちらで作る（元のPC用は残す）
  2. 複製したアバターのマテリアルを VRChat/Mobile/Toon Lit などに差し替える

自動で調べたいなら：改変おたすけ診断がQuestで使えないシェーダーと書き出し先を1クリックで調べます（無料版あり）。無料で試す

画面に出る文字：

Avatar uses unsupported shader '…'. You can only use the shaders provided in 'VRChat/Mobile' for Quest avatars.

意味

書き出し先をQuest（Android）にしたとき、Questで使えないシェーダーが入っています。Quest版のアバターは VRChat/Mobile のシェーダーしか使えないので、ピンク色になったりアップロードできなかったりします。

よくある原因

  • PC用のアバターをそのままAndroidに切り替えた
  • lilToon・Poiyomi などPC用のシェーダーのまま

直し方

  1. アバターを複製して、Quest用はそちらで作る（元のPC用は残す）
  2. 複製したアバターのマテリアルを VRChat/Mobile/Toon Lit などに差し替える
  3. ポリゴン数・マテリアル数もQuestの上限に収まるか確かめる

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります（有料版は多くを1クリックで直します）。
この症状では：Questで使えないシェーダーを一覧にし、有料版なら1クリックでQuest用の複製を作ってシェーダーを差し替えます（元のアバターはそのまま）。
改変おたすけ診断（無料版あり）

関係するエラー

  • Quest版で髪やスカートが揺れない（PhysBoneの上限）
  • アバターが Very Poor / Poor になる（PC・Questの上限の意味と直し方）
  • アバター・衣装がピンク色（マゼンタ）になる
  • 上げたアバターが出てこない・ほかの人には別のアバター（ロボット）に見える
