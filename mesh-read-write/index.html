meshes that were imported with Read/Write disabled（メッシュの Read/Write がオフ）

まずはこれ
  1. Projectでモデルのファイル（.fbx）を選ぶ
  2. Inspectorの Model タブで「Read/Write」にチェックを入れる

自動で調べたいなら：改変おたすけ診断がこの設定を1クリックで見つけます（無料版あり）。無料で試す

画面に出る文字：

This avatar contains meshes that were imported with Read/Write disabled. This must be fixed in the mesh import settings before uploading.

意味

モデル（FBX）の読み込み設定で Read/Write がオフになっています。この設定のままではアップロードできません。

よくある原因

  • 小物（椅子・武器・アクセサリー）や新しい服を入れた
  • モデルを読み込むときに Read/Write をオフにした

直し方

  1. Projectでモデルのファイル（.fbx）を選ぶ
  2. Inspectorの Model タブで「Read/Write」にチェックを入れる
  3. Apply を押してからもう一度アップロード

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります（有料版は多くを1クリックで直します）。
この症状では：オフになっているモデルを一覧にし、有料版なら1クリックでオンにします。
改変おたすけ診断（無料版あり）

関係するエラー

  • Blendshape Normals set to 'Calculate' but aren't using 'Legacy Blendshape Normals'
  • particle systems configured to destroy themselves（エフェクトが自分を消す設定）
  • uses a parameter that is not defined（メニューのパラメータ）
  • 同期パラメータが256bitを超えている
