テクスチャのメモリ（Texture Memory）が多すぎる・減らし方

まずはこれ
  1. Projectで画像を選び、Max Size を下げる（4096→2048 にするとメモリはおよそ4分の1）
  2. Compression を Normal Quality にする（High Quality はダウンロード・展開後の容量が増える）

自動で調べたいなら：Performance Rank DoctorがPC・Questのランクを下げている項目を理由つきで一覧にします（無料版あり）。無料で試す

画面に出る文字：

Texture Memory: … MB（SDKのパフォーマンス表示）

意味

テクスチャのメモリは、アバターの画像が表示のために使う量です。PCは Excellent 40MB・Good 75MB・Medium 110MB・Poor 150MB、Questは 10・18・25・40MB が目安です。メモリが多すぎると、Security Checks Failed の原因にもなります。

よくある原因

  • 4096（4K）の画像をそのまま使っている
  • 圧縮がオフ（None）になっている
  • 使っていない服・小物の画像も入っている
  • Android版でもPC用の設定のまま

直し方

  1. Projectで画像を選び、Max Size を下げる（4096→2048 にするとメモリはおよそ4分の1）
  2. Compression を Normal Quality にする（High Quality はダウンロード・展開後の容量が増える）
  3. Crunch Compression はダウンロードの大きさを減らすが、表示のときは元に戻るのでメモリはほとんど減らない
  4. Android版は、画像の設定の Android タブで Override をオンにし、ASTC と小さめの Max Size にする
  5. 使っていない服・小物を消すか、AAOなどで使っていない画像を外す
  6. Apply を押し、ビルドしてSDKのTexture Memoryを見直す

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityで「診断する」を押すだけで、PC・Questのランクを下げている項目と、直すと何ランク上がるかを一覧にする道具です（有料版はよくある原因を1クリックで直します）。
この症状では：テクスチャのメモリを数え、重い画像とPC版のランクの見込みを出します。
Performance Rank Doctor（無料版あり）

関係するエラー

  • アバターが Very Poor / Poor になる（PC・Questの上限の意味と直し方）
  • Security Checks Failed が出る（アバターが使えない・アップロードできない）
  • This avatar has mipmapped textures without 'Streaming Mip Maps' enabled
  • Avatar uses unsupported shader（Quest版でピンク・アップロードできない）
  • meshes that were imported with Read/Write disabled（メッシュの Read/Write がオフ）
