VRChat改変エラー辞典

Security Checks Failed が出てアップロードできない

画面に出る文字：

Security Checks Failed

意味

アップロード前の安全チェックで止められています。Macで改変している人に特に多いエラーです。

よくある原因

  • 書き出し先（Build Target）がMacやiOSのままになっている
  • Windows向けでないと、PC版VRChatへのアップロードは通りません

直し方

  1. Unityの上のメニュー File → Build Settings を開く
  2. 「Windows, Mac, Linux」を選ぶ
  3. Target Platform を Windows にする
  4. Switch Platform を押し、終わるまで待ってからもう一度アップロード

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自分のプロジェクトで原因を探すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります。
この症状では：書き出し先がWindowsかを調べ、有料版なら1クリックで切り替えます。
改変おたすけ診断（無料版あり）
