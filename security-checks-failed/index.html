EnglishVRChat改変エラー辞典

Security Checks Failed が出る（アバターが使えない・アップロードできない）

画面に出る文字：

Security Checks Failed（名札に出る・アバター一覧の画像が灰色で×）

意味

VRChatは、上げたアバターをサーバーで安全チェックしています。通らなかったアバターは読み込まれず、名札に「Security Checks Failed」と出て、アバター一覧の画像が灰色になり右上に×が付き、着替えられません。右上が「?」なら、まだチェックが終わっていないだけです。VRChatは1体ずつ例外を認めないので、アバターを直して上げ直すのが解決です。

よくある原因

  • メモリを使いすぎている（VRChatによると多い原因。大きいテクスチャがよくある元）
  • 容量の上限を超えている：PCはダウンロード200MB・展開後500MB、Android（Quest）は10MB・40MB。古いSDKだと上がってしまい、サーバーで止められる
  • アップロードのときに動く道具が、アバターをふつうでない形に変えている
  • VRChat SDKが古い
  • 上げる前に止まる場合：Macで書き出し先（Build Target）がMacのままになっている

直し方

  1. 右上が×でなく「?」なら、チェックが終わるまで待つ
  2. ALCOM（またはVCC）でVRChat SDKを最新にする
  3. SDKの画面の Validations の赤い項目を全部直し、ビルドのあとに出るダウンロード・展開後の容量を見る
  4. テクスチャのメモリを減らす：大きいテクスチャの Max Size を 2048 か 1024 にし、圧縮をオンのままにする
  5. アップロード時に動く道具を使っているなら、外したテスト用の複製を上げて、どれが原因か確かめる
  6. 上げる前に止まる（Macの場合）：File → Build Settings → Windows → Switch Platform のあと、もう一度アップロード
  7. それでも通らなければ、アバターIDを書いてVRChatのサポートに問い合わせる

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自分のプロジェクトで原因を探すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります。
この症状では：書き出し先とテクスチャのメモリを調べ、止められやすい設定を一覧にします。有料版なら書き出し先を1クリックで切り替えます。
