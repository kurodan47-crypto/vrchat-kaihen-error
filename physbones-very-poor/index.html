PhysBone が多すぎて Very Poor になる（Components・Transforms・Colliders）・減らし方

まずはこれ
  1. SDKの画面（Builder）でランクの内訳を開き、PhysBone の4つの数のどれが一番悪いかを見る
  2. 着ない服・小物の PhysBone は、服ごと消す（オフにしても数は減らない）

自動で調べたいなら：Performance Rank DoctorがPC・Questのランクを下げている項目を理由つきで一覧にします（無料版あり）。無料で試す

画面に出る文字：

PhysBones Components / Affected Transforms / Colliders / Collision Check Count: …（SDKのランクの内訳）

意味

PhysBone は4つの数でランクが決まります。PCの上限（Excellent / Good / Medium / Poor）は、コンポーネント 4 / 8 / 16 / 32、動く骨（Affected Transforms）16 / 64 / 128 / 256、コライダー 4 / 8 / 16 / 32、当たり判定の回数（Collision Check Count）32 / 128 / 256 / 512 で、1つでも Poor を超えると Very Poor です。Quest（スマホ）の Poor はコンポーネント8・動く骨64・コライダー16・当たり判定64で、超えるとスマホでは PhysBone・Contact・Constraint が全部外されます（Show Avatar を押しても外れたまま）。オフにしたコンポーネントも数に入ります。当たり判定の回数は「各コライダーが触れる骨の数」の合計なので、3つのコライダーが触れる骨は3回数えられます。

よくある原因

  • 服ごとに PhysBone（スカート・リボン・フードなど）が付いていて、服をオフにしても残っている
  • 髪の房やリボン1本ずつに、別々の PhysBone が付いている
  • 骨の数が多い長い鎖がある
  • 長い鎖にコライダーをたくさん入れていて、当たり判定の回数がかけ算で増えている
  • Quest版でもPC版の PhysBone をそのまま使っている

直し方

  1. SDKの画面（Builder）でランクの内訳を開き、PhysBone の4つの数のどれが一番悪いかを見る
  2. 着ない服・小物の PhysBone は、服ごと消す（オフにしても数は減らない）
  3. 同じ部位の鎖は1つにまとめる：共通の親の骨（髪の根元など）に PhysBone を1つだけ付けると、その下の鎖が全部動く。親の骨を動かしたくなければ Multi-Child Type を Ignore にする。AAO の Merge PhysBone でもアップロードの時にまとめられる
  4. 当たらなくていい鎖（小さいアクセサリー・短いリボン）からコライダーを外し、長い鎖のコライダーは少なくする
  5. ほとんど目立たない短い鎖は、PhysBone を外す
  6. Ignore Transforms で骨を外したときは、ビルドしてから数を見直す（外した骨が数に入ったままになる例が報告されている）
  7. Quest用は複製して作り、髪とスカートを優先して、コンポーネント8・動く骨64以内に収める

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。
