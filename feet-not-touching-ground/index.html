自動で調べたいなら：Avatar Grounding Fixerが靴底と目線（View Position）のずれをcmで測ります（無料版あり）。無料で試す

画面に出る文字：

（エラー文は出ず、足が床から浮く・沈む）

意味

モデルの足元と、Unityの地面（Y=0）がずれています。浮くときは足元が原点より上、沈むときは下にあります。ヒールの靴や厚底の衣装を着せたときにも起きます。

よくある原因

  • アバターの足元が原点（Y=0）からずれている
  • ヒール・厚底の靴を着せて、足の位置だけ高くなった
  • 衣装の Armature に大きさの変更（Scale）が入っている
  • View Position の高さが体と合っていない

直し方

  1. シーンを横から見て、靴の裏とY=0の線がそろっているか確かめる
  2. アバターの Transform の Position を (0, 0, 0) にする
  3. ヒールの靴なら、靴の説明書にある高さ合わせ（ギミック・設定）を使う
  4. View Position を目と目のあいだに置き直す

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityで「診断する」を押すだけで、靴底と地面のずれ・目線（View Position）のずれをcmで測り、ルートやリグも調べる道具です（有料版はまとめて1クリックで直します）。
この症状では：Humanoid の設定とAvatar Descriptorがそろっているかを調べます（足の高さは測りません）。

関係するエラー

  • アップロードしたらアバターが浮いている
  • 目線（カメラの位置）がずれる・体の中から見える
  • 指が動かない（グーやピースにならない）
  • 非対応衣装が体についてこない（ボーン名のちがい）
