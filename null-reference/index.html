NullReferenceException（空の参照）

まずはこれ
  1. エラーに出ているツール名を最新にする
  2. 直らなければ、そのツールの説明書・配布ページを確認

自動で調べたいなら：改変おたすけ診断が赤エラーの説明と足りない道具を1クリックで出します（無料版あり）。無料で試す

画面に出る文字：

NullReferenceException: Object reference not set to an instance of an object

意味

ツールが、空っぽの物を使おうとして止まりました。

よくある原因

  • ツールの版ちがい
  • 必要な欄が空のまま

直し方

  1. エラーに出ているツール名を最新にする
  2. 直らなければ、そのツールの説明書・配布ページを確認

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります（有料版は多くを1クリックで直します）。
この症状では：このエラーが出ていれば、日本語で直し方を出します。
改変おたすけ診断（無料版あり）

関係するエラー

  • 部品（パッケージ）が読み込めない（Failed to resolve packages）
  • フォルダの場所（パス）の問題：日本語・長すぎるパス
  • Dynamic Bone（古い揺れもの）が残っている
  • All compiler errors have to be fixed before you can enter playmode
