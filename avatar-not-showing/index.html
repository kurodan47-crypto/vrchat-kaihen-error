自動で調べたいなら：改変おたすけ診断がアップロードを止めている所を1クリックで見つけます（無料版あり）。無料で試す

画面に出る文字：

（エラーは出ず、一覧に無い・フレンドからは灰色のロボットや別のアバターに見える）

意味

まず2つに分けます。①自分でも見つからない、②自分には見えるのにほかの人には別の物に見える。②は、相手の「表示する最低ランク」より重い、相手の容量の上限を超えている、相手の機種向けの版が無い（Questの人向けのAndroid版が無いなど）、Security Checks Failed、相手の安全設定で隠れている、のどれかで起きます。

よくある原因

  • SDKで別のアカウントに上げた
  • VRChatより新しいUnityで上げた（VRChatによると、メニューに出てきません）
  • 相手がQuest・Androidで、Android版が無い
  • Quest・Androidは初期設定でPoor・Very Poorを隠す（Medium以上だけ表示）。PCの初期設定はVery Poorまで表示
  • 相手の容量の上限を超えている
  • Security Checks Failed になっている
  • 相手の安全設定（Trust Rankごとの表示）で隠れている、または相手が手で隠した

直し方

  1. SDKとVRChatで同じアカウントにログインしているか確かめ、そのアカウントで探す
  2. UnityをVRChatの指定の版にして上げ直す
  3. Questのフレンドにロボットに見えるなら、同じBlueprint IDにAndroid版を上げ、Medium以上にする
  4. 一覧の画像に×が付いていれば、Security Checks Failed のページを見る
  5. フレンドに自分を選んで Show Avatar を押してもらう。見えれば、上げ方ではなく相手の設定（ランク・容量・安全設定）が原因

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります（有料版は多くを1クリックで直します）。
この症状では：上げる前に、Unityの版・書き出し先・パフォーマンスランクの見込みを調べます。

関係するエラー

  • Security Checks Failed が出る（アバターが使えない・アップロードできない）
  • Avatar uses unsupported shader（Quest版でピンク・アップロードできない）
  • Quest版で髪やスカートが揺れない（PhysBoneの上限）
  • 他人のアバターの番号が残っている（avatar we do not own）
