This avatar uses a mixture of Write Defaults（表情やギミックが戻らない）

まずはこれ
  1. どちらかにそろえる（多い方に合わせるのが安全）
  2. ギミックの説明書に指定があれば、それに合わせる

自動で調べたいなら：改変おたすけ診断がパラメータとアニメーターのレイヤーを1クリックで調べます（無料版あり）。無料で試す

画面に出る文字：

This avatar uses a mixture of Write Defaults in its animator states. To avoid animation issues, VRChat recommends using the same Write Defaults setting across all animator states.

意味

同じアバターのアニメーターの中で、Write Defaults（アニメが終わったら元の値に戻すか）のオンとオフが混ざっています。アップロードは止まりませんが、表情が戻らない・混ざる・ギミックが戻らない原因になります。

よくある原因

  • Write Defaults の設定がちがうギミックや表情を、いくつも入れた
  • アバター付属のアニメーターと、あとから足したアニメーターで設定がちがう

直し方

  1. どちらかにそろえる（多い方に合わせるのが安全）
  2. ギミックの説明書に指定があれば、それに合わせる
  3. Modular Avatar で入れたギミックなら、Merge Animator の「Match Avatar Write Defaults」をオンにする

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります（有料版は多くを1クリックで直します）。
この症状では：オン・オフが混ざっているアニメーターと、そのレイヤーを一覧にします。
改変おたすけ診断（無料版あり）

関係するエラー

  • FXレイヤーの重みが0で、表情・ギミックが動かない
  • ラジアル（スライダー）のシェイプキーが100を超えない・ほかの人とずれる
  • トグル（服の着脱など）がほかの人に同期しない
  • トグルの状態が保存されない（着替えるたびに戻る）
