VRChat改変エラー辞典

All compiler errors have to be fixed before you can enter playmode

画面に出る文字：

All compiler errors have to be fixed before you can enter playmode!

意味

どこかのスクリプトに赤エラーがあり、再生もアップロードもできない状態です。このメッセージ自体は原因ではありません。

よくある原因

  • 必要な部品（VRChat SDK・Modular Avatar・lilToonなど）の入れ忘れ
  • 部品の版がアバター・衣装の指定と合っていない
  • 古いSDKがAssetsフォルダに残っていて二重になっている

直し方

  1. Consoleを開き、Clearを押してから、残った赤エラーの一番上を読む
  2. エラーに出てくる名前（VRC・nadena・lilToon など）の部品をALCOM（またはVCC）で入れる・更新する
  3. Assets/VRCSDK など古いSDKのフォルダが残っていたら、プロジェクトを複製してから消す

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自分のプロジェクトで原因を探すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります。
この症状では：赤エラーを日本語で説明し、足りない部品や古いSDKの重なりも調べます。
改変おたすけ診断（無料版あり）
