編集した顔（シェイプキー）が表情やなでなでで元に戻る

まずはこれ
  1. Animator で FX の各レイヤー・各ステートを開き、表情のアニメに変えたシェイプキーが入っていないか探す
  2. 入っていたら、そのキーの値を今の顔の値にそろえる（表情でわざと動かすキーはそのまま）

自動で調べたいなら：Face Shape Keeperが編集した顔を元に戻しているアニメと、戻るタイミングを見つけます（無料版あり）。無料で試す

画面に出る文字：

（エラー文は出ず、Unityで作った顔がVRChatで戻る・出ない）

意味

表情やなでなで（頭をなでられた時）のアニメが、あなたが変えた顔のシェイプキーを元の値で書き戻しています。後ろのFXレイヤーほど強いので、表情のアニメがあなたの顔を上書きします。

よくある原因

  • Unityで顔のシェイプキー（目の大きさ・輪郭など）を変えた
  • 表情・なでなで・メニューのアニメに、同じシェイプキーが元の値（0など）で入っている
  • いつも動く待機のアニメに同じキーが入っていると、VRChatでは最初から顔が出ない

直し方

  1. Animator で FX の各レイヤー・各ステートを開き、表情のアニメに変えたシェイプキーが入っていないか探す
  2. 入っていたら、そのキーの値を今の顔の値にそろえる（表情でわざと動かすキーはそのまま）
  3. FaceEmo や Modular Avatar で作った表情なら、その元のアニメ側を直して作り直す
  4. アップロードして、表情を変えた時・なでられた時に顔が戻らないか確かめる

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityの窓に、編集した顔のシェイプキーを元に戻しているアニメと、戻るタイミング（いつも・表情・なでなで・メニュー）を一覧にする道具です（有料版は笑顔・まばたき・口パクは動いたまま、今の顔を1クリックで保ちます）。
この症状では：どのアニメがいつ顔を戻しているか（いつも・表情・なでなで・メニュー）を一覧にし、有料版なら笑顔・まばたき・口パクは動いたまま、今の顔を1クリックで保ちます。
