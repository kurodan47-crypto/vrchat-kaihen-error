VRChat "This avatar uses a mixture of Write Defaults" - expressions not resetting fix

What you see on screen:

This avatar uses a mixture of Write Defaults in its animator states. To avoid animation issues, VRChat recommends using the same Write Defaults setting across all animator states.

What it means

Write Defaults (whether values reset after an animation ends) is on in some animator states and off in others. It doesn't block the upload, but it causes expressions that don't reset, mixed expressions, and gimmicks that don't turn off.

Common causes

  • You added several gimmicks or expressions with different Write Defaults settings
  • The avatar's own animators and the ones you added later use different settings

How to fix it

  1. Make them all the same (matching the majority is safest)
  2. If a gimmick's readme specifies a setting, follow it
  3. For gimmicks added with Modular Avatar, turn on "Match Avatar Write Defaults" in Merge Animator

Before you change anything, make a full copy of your project folder so you can go back.
