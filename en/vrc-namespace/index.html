"The type or namespace name 'VRC' could not be found" (CS0246) - VRChat SDK fix

What you see on screen:

error CS0246: The type or namespace name 'VRC' could not be found

What it means

Unity can't find or load the VRChat SDK.

Common causes

  • VRChat SDK - Avatars is not installed
  • The project was created without VCC/ALCOM
  • The SDK failed to load because of another error

How to fix it

  1. Open this project in VCC (or ALCOM)
  2. Add "VRChat SDK - Avatars" (or update it to the latest version if it's already there)
  3. Reopen Unity

Before you change anything, make a full copy of your project folder so you can go back.
