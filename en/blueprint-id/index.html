VRChat Blueprint ID problems when uploading an avatar - fix

What you see on screen:

Blueprint ID … / blueprint

What it means

The upload destination ID doesn't match your account.

Common causes

  • Someone else's Blueprint ID is still attached

How to fix it

  1. Press "Detach" on the Pipeline Manager, then upload again

Before you change anything, make a full copy of your project folder so you can go back.
