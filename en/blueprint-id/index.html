VRChat Blueprint ID problems: detach, reuse, or upload as a new avatar

What you see on screen:

Blueprint ID … / blueprint

What it means

The Blueprint ID decides which avatar on your account gets updated. If it belongs to someone else or another account, the upload fails or becomes a new avatar. To update an avatar you already uploaded, the same ID must be set.

Common causes

  • Someone else's Blueprint ID is still attached
  • You want to update an existing avatar but the ID was cleared
  • PC and Quest versions were uploaded to different IDs

How to fix it

  1. To start fresh: press "Detach" on the Pipeline Manager, then upload again
  2. To update an existing avatar: copy its ID from the SDK's content list and paste it into the Pipeline Manager (Attach), then upload
  3. For PC + Quest, upload both versions to the same Blueprint ID so Quest users see the Android version

Before you change anything, make a full copy of your project folder so you can go back.
