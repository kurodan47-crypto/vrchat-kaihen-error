(No error message - the face you made in Unity goes back or never shows in VRChat)

What it means

An expression or head pat animation writes your edited face shape keys back to their original values. Later FX layers win, so the expression animation overrides the face you made.

Common causes

  • You changed face shape keys (eye size, face shape and so on) in Unity
  • An expression, head pat or menu animation has the same shape keys at their original values (often 0)
  • If an always-on idle animation has those keys, the face you made never shows in VRChat

How to fix it

  1. Open each FX layer and state in the Animator and look for your edited shape keys inside the expression animations
  2. If they are there, set those keys to your current face values (leave keys an expression moves on purpose)
  3. For FaceEmo or Modular Avatar expressions, fix the source animation and generate again
  4. Upload and check that the face stays when your expression changes and when someone pats you

Before you change anything, make a full copy of your project folder so you can go back.
