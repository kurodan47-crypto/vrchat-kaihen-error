FaceEmo not installed (Missing Script on facial expression menu) - VRChat fix

What you see on screen:

The referenced script on this Behaviour is missing! (FaceEmo components)

What it means

FaceEmo components are still on the avatar, but FaceEmo itself isn't installed. The expression menu can't be built and expressions won't work.

Common causes

  • You brought an avatar whose expressions were made with FaceEmo into another project
  • You added an expression set without installing FaceEmo

How to fix it

  1. Add the FaceEmo repository (https://suzuryg.github.io/vpm-repos/vpm.json) to VCC (or ALCOM)
  2. Install FaceEmo in this project
  3. Open the FaceEmo window and apply it to the avatar again

Before you change anything, make a full copy of your project folder so you can go back.
