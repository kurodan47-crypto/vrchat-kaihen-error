What you see on screen:

Texture Memory: … MB (SDK performance stats)

What it means

Texture memory is how much memory your avatar's textures take up when displayed. PC ranks: Excellent 40 MB, Good 75 MB, Medium 110 MB, Poor 150 MB. Quest/mobile: 10, 18, 25 and 40 MB. Very high memory use is also a common reason for Security Checks Failed.

Common causes

  • 4096 (4K) textures used as-is
  • Compression set to None
  • Textures from unused outfits or props still included
  • The Android version still uses PC texture settings

How to fix it

  1. Select textures in the Project window and lower Max Size (4096 to 2048 cuts memory to about a quarter)
  2. Set Compression to Normal Quality (High Quality increases download and uncompressed size)
  3. Crunch Compression shrinks the download, but textures are expanded again for display, so it barely lowers texture memory
  4. For Android, turn on Override in the texture's Android tab and use ASTC with a smaller Max Size
  5. Delete unused outfits and props, or strip unused textures with a tool such as AAO
  6. Press Apply, build, and check Texture Memory in the SDK again

Before you change anything, make a full copy of your project folder so you can go back.
