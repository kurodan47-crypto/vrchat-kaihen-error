VRChat eyes twitching / blinking during a closed-eye expression - fix

What you see on screen:

(No error message - the eyes twitch when an expression is on)

What it means

The closed-eye expression is fighting with the avatar's automatic blinking. Even when your expression closes the eyes, auto-blink moves the same blendshape, so the eyes twitch or open.

Common causes

  • You made or added a closed-eye or half-closed-eye expression
  • The expression animation has no setting to stop blinking (Tracking Control)

How to fix it

  1. Select the closed-eye expression state in the Animator
  2. Add Behaviour > VRC Animator Tracking Control, and set Eyes & Eyelids to Animation
  3. In the state that returns to the normal face, set it back to Tracking

Before you change anything, make a full copy of your project folder so you can go back.
