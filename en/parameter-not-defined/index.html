VRChat "VRCExpressionsMenu uses a parameter that is not defined" - fix

What you see on screen:

VRCExpressionsMenu uses a parameter that is not defined. Parameter: …

What it means

An item in your Expressions Menu uses a parameter that isn't registered in Expression Parameters.

Common causes

  • A gimmick was removed but its menu item stayed
  • An outfit menu was added without adding its parameters

How to fix it

  1. Open the Expressions Menu (and its submenus) and check each item
  2. Register the parameter in Expression Parameters, or delete the menu item

Before you change anything, make a full copy of your project folder so you can go back.
