lilToon errors and pink lilToon materials in VRChat - how to fix

What you see on screen:

lilToon … / Shader error in 'lilToon'

What it means

The lilToon shader, which controls how the avatar looks, is missing or the wrong version.

Common causes

  • lilToon is not installed
  • The version is too old or too new
  • Materials lost their link to the shader during a reinstall

How to fix it

  1. Add or update lilToon in VCC (or ALCOM)
  2. If it's still pink, select the material and pick lilToon again under Shader in the Inspector
  3. If the avatar's readme names a specific version, match it

Before you change anything, make a full copy of your project folder so you can go back.
