"All pipe instances are busy" when building a VRChat avatar - fix

What you see on screen:

All pipe instances are busy

What it means

A temporary build failure.

Common causes

  • Unity's internal communication got stuck

How to fix it

  1. Restart Unity
  2. Build and upload again

Before you change anything, make a full copy of your project folder so you can go back.
