Missing Prefab in Unity (red object names in the Hierarchy) - VRChat avatar fix

What you see on screen:

Missing Prefab / object names shown in red in the Hierarchy

What it means

The source file (prefab) of something in your scene can't be found.

Common causes

  • The original prefab was deleted or moved
  • unitypackages were imported in the wrong order
  • A reimport replaced it with something else

How to fix it

  1. Import the outfit's or avatar's unitypackage again
  2. If that doesn't work, duplicate the red object as a backup, delete it, and place the prefab again

Before you change anything, make a full copy of your project folder so you can go back.
