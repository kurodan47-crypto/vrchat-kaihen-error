NullReferenceException in a VRChat avatar project - what it means and fixes

What you see on screen:

NullReferenceException: Object reference not set to an instance of an object

What it means

A tool tried to use something that was empty and stopped.

Common causes

  • Tool version mismatch
  • A required field was left empty

How to fix it

  1. Update the tool named in the error to the latest version
  2. If that doesn't fix it, check that tool's readme or download page

Before you change anything, make a full copy of your project folder so you can go back.
