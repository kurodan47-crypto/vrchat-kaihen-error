Inspector fields showing "Missing" in Unity - how to fix broken references

What you see on screen:

Missing (Transform) / Missing (Material), etc.

What it means

The file or object a field pointed to was deleted, so the link is broken. Unlike "None", "Missing" means something used to be there.

Common causes

  • Outfit bones or parts were deleted
  • The original file was deleted or reimported

How to fix it

  1. Select the object and look for "Missing" fields in the Inspector
  2. Assign the correct object again
  3. If deleted bones are the cause, reimport the original unitypackage

Before you change anything, make a full copy of your project folder so you can go back.
