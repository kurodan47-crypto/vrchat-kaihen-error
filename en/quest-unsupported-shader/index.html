What you see on screen:

Avatar uses unsupported shader '…'. You can only use the shaders provided in 'VRChat/Mobile' for Quest avatars.

What it means

With the build target set to Quest (Android), the avatar uses shaders Quest can't run. Quest avatars can only use VRChat/Mobile shaders, so they show up pink or fail to upload.

Common causes

  • A PC avatar was switched straight to Android
  • PC shaders such as lilToon or Poiyomi are still in use

How to fix it

  1. Duplicate the avatar and make the Quest version from the copy (keep the PC original)
  2. Change the copy's materials to VRChat/Mobile/Toon Lit or similar
  3. Check that polygon and material counts fit Quest limits

Before you change anything, make a full copy of your project folder so you can go back.
