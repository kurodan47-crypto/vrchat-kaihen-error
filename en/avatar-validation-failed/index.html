VRChat "Avatar validation failed" when uploading - how to find the real cause

What you see on screen:

Avatar validation failed

What it means

This is a general message: the SDK's checks stopped the build, but the message itself doesn't say why. The real reason is in the SDK control panel's Validations list or earlier in the Unity Console. A "clearing blueprint ID" line right after it can usually be ignored.

Common causes

  • A red item in Validations (undefined menu parameters, missing Expressions Menu/Parameters, oversized icons, audio/texture/mesh import settings, etc.)
  • Over the size limits: PC 200 MB download / 500 MB uncompressed, Android (Quest) 10 MB / 40 MB
  • On Android/Quest: unsupported shaders or other mobile limits
  • A tool that runs at upload time (Modular Avatar, VRCFury, etc.) threw an error during the build
  • An outdated SDK

How to fix it

  1. Open VRChat SDK > Show Control Panel > Builder and read every red item under Validations (red blocks the upload; yellow is only a warning)
  2. Open the Console, press Clear, build again, and read the first red error above "Avatar validation failed"
  3. Search for that error on this site and fix it
  4. Update the VRChat SDK and your tools (Modular Avatar, VRCFury, etc.) in VCC or ALCOM
  5. If nothing shows up, try turning a VPN/WARP off, reopen the SDK panel, and log in again

Before you change anything, make a full copy of your project folder so you can go back.
