Missing Script on a VRChat avatar ("The referenced script on this Behaviour is missing") - fix

What you see on screen:

The referenced script on this Behaviour is missing! / Missing (Mono Script)

What it means

The tool that created this component isn't installed, or it's the wrong version. Missing Scripts can block your upload.

Common causes

  • A tool the outfit depends on (Modular Avatar, VRCFury, etc.) isn't installed
  • Version mismatch

How to fix it

  1. Install everything in the readme's "requirements" section
  2. If you don't know which tool is missing, it can be identified from the ID (GUID) left on the missing component. Avatar Setup Doctor names Modular Avatar, VRCFury, AAO, lilycalInventory, FaceEmo, lilToon, Poiyomi and the VRChat SDK and shows where to get them
  3. If some remain and you don't need them, remove them (Remove Missing Script)

Before you change anything, make a full copy of your project folder so you can go back.
