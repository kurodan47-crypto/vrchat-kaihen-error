"Loaded data for an avatar we do not own, clearing blueprint ID" in VRChat - what it means and fix

What you see on screen:

Attempting to upload an avatar we do not own / Loaded data for an avatar we do not own, clearing blueprint ID

What it means

The upload destination ID (Blueprint ID) on the Pipeline Manager points to an avatar that isn't owned by the account you're logged into. The SDK clears it and uploads as a new avatar. If this line appears right after "Avatar validation failed", it's usually just a side effect - the real problem is the error before it.

Common causes

  • The purchased avatar prefab (from Booth, Gumroad, Jinxxy, etc.) still has the creator's Blueprint ID
  • You reused an avatar uploaded from another account
  • You're logged into a different account than the one that uploaded it
  • Avatar validation failed first, and this message followed

How to fix it

  1. If "Avatar validation failed" appears just before it, fix that first (see the Avatar validation failed page)
  2. Select the avatar and press "Detach" on the Pipeline Manager
  3. Log out in the SDK panel, restart Unity, and log in with the account you want to upload to
  4. Upload again - it will be created as a new avatar

Before you change anything, make a full copy of your project folder so you can go back.
