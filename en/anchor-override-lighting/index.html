What you see on screen:

(No error. Body, clothes or hair show different brightness or color in some worlds)

What it means

Each mesh picks up the world's light (light probes and reflection probes) at one point. If you set nothing, that point is the center of the mesh's own Bounds, so the body, the outfit and the hair each read the light from a different spot and look differently lit. Anchor Override lets you choose that point. When every mesh uses the same one, they are lit the same.

Common causes

  • Anchor Override is empty on some meshes, or points to a different bone on each mesh
  • An outfit added later keeps its own setting
  • Bounds and Root Bone differ between meshes, so the points where they read the light are far apart
  • The materials use different shaders or lighting settings (for example lilToon's light limits) - Anchor Override does not fix that

How to fix it

  1. Pick one bone as the anchor - Chest or Hips are common
  2. Select every Skinned Mesh Renderer and Mesh Renderer on the avatar (multi-select works) and drag that bone into Anchor Override, under Probes
  3. With Modular Avatar, add MA Mesh Settings to the avatar root and set Anchor Override there (outfits added with Setup Outfit follow it)
  4. If the brightness still differs, compare the lighting settings of the body and outfit materials
  5. Upload and check in a world with strong light differences, such as a room with colored lights

Before you change anything, make a full copy of your project folder so you can go back.
