"Security Checks Failed" when uploading a VRChat avatar - how to fix

What you see on screen:

Security Checks Failed

What it means

The SDK's pre-upload safety check stopped your build. This is especially common if you edit avatars on a Mac.

Common causes

  • The Build Target is still set to macOS or iOS
  • PC VRChat only accepts avatars built for Windows

How to fix it

  1. In Unity, open File > Build Settings
  2. Select "Windows, Mac, Linux"
  3. Set Target Platform to Windows
  4. Press Switch Platform, wait until it finishes, then upload again

Before you change anything, make a full copy of your project folder so you can go back.
