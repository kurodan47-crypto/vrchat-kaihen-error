What you see on screen:

VRCExpressionsMenu object reference is missing. (or) VRCExpressionParameters object reference is missing.

What it means

The VRChat SDK shows this red error when only one of Menu and Parameters is set under Expressions on the Avatar Descriptor and the other is empty (None). The SDK checks: if either one is set, are both set? The first message means Menu is empty; the second means Parameters is empty. If both are empty, the check is skipped and no error appears (the avatar uploads with VRChat's default menu). If you build while this red item is still there, the build stops with "Avatar validation failed".

Common causes

  • You swapped the menu (or the parameters) and only filled in one of them, or cleared one
  • The file in the field was deleted, moved or re-imported (the field shows None or Missing)
  • One field got cleared after you re-installed a gimmick or a facial expression tool

How to tell which cause it is

  • You see "VRCExpressionsMenu object reference is missing."
    → The Menu field is empty; Parameters is set
  • You see "VRCExpressionParameters object reference is missing."
    → The Parameters field is empty; Menu is set
  • Expressions only shows a Customize button
    → The fields are just hidden. Press Customize to show Menu and Parameters
  • A field says "Missing"
    → The file it pointed to was deleted or moved. Find the original file and assign it again

How to fix it

  1. In VRChat SDK > Show Control Panel > Builder, find this red item under "2. Review Any Alerts" and press Select next to it (it selects the avatar's Avatar Descriptor)
  2. In the Inspector, open Expressions on the VRC Avatar Descriptor and look for the empty (None) field. If you only see a Customize button, press it to show the Menu and Parameters fields
  3. If Parameters is empty: click the Menu file that is still set and look at its Parameters field in the Inspector - that is the matching Parameters file
  4. If Menu is empty: type t:VRCExpressionsMenu in the Project window's search box and find the menu file in your avatar's folder
  5. Drag the file you found into the empty field on the Avatar Descriptor
  6. Only if the matching file doesn't exist anywhere: right-click in the Project window > Create > VRChat > Avatars > Expressions Menu (or Expression Parameters), then assign the new file
  7. If you don't need your own menu: press Reset To Default under Expressions and confirm with OK (both fields are cleared and VRChat's default menu is used)
  8. Check that the red item is gone from Review Any Alerts, then build again

Common mistakes

  • The two messages never appear together. If both fields are empty, the check is skipped and VRChat's default menu is used.
  • If you fill the empty field with a brand-new empty file, this error goes away, but you may get "VRCExpressionsMenu uses a parameter that is not defined." instead, because the menu's buttons use names the new parameter list doesn't have. Look for the original file first.
  • Reset To Default only clears the two fields on the Avatar Descriptor. It doesn't delete the Menu or Parameters files, so you can assign them again later.

FAQ

Do I have to set both Menu and Parameters?

Setting only one won't pass. Set both, or clear both with Reset To Default. With both empty the check is skipped and you can upload with VRChat's default menu.

Which file should I use?

The original pair that came with your avatar. Click the Menu file and its matching Parameters file is shown in the Parameters field in the Inspector. If a gimmick's readme names a different file, use that one.

I fixed it but the red item is still there

Review Any Alerts re-checks a moment after a change (about 2 seconds on SDK 3.10.6). If it's still there after that, check that the avatar selected in the Builder is the one you just fixed.

It appeared together with "Avatar validation failed"

You built while this red item was still there. The message is listed below "Encountered the following validation issues during build:" in the Console. Fix the field, and if nothing else is red, the build goes through.

Before you change anything, make a full copy of your project folder so you can go back.
