What you see on screen:

(No error message - pressing the toggle in the Action Menu does nothing, even on your own screen)

What it means

A menu toggle only works when four links line up: the menu control, a parameter with the same name in Expression Parameters, a parameter with the same name in the FX animator, and an animation that points to the right object. If any link is broken, the toggle does nothing and no error appears. If it works on your screen but others don't see it, that is a sync problem - see the toggles not syncing page.

Common causes

  • The parameter name differs between the menu, Expression Parameters and the animator (upper and lower case count, and so does a space at the end)
  • The object was renamed or moved after the animation was made, so the animation points to a path that no longer exists (shown in yellow as "Missing!" in the Animation window)
  • The toggle layer was added to the Gesture or Base animator instead of FX - object toggles and shape keys belong in FX
  • The FX layer's Weight is still 0
  • The transition conditions are wrong: a different parameter, true and false swapped, or Has Exit Time left on
  • A later FX layer writes the same object or shape key and wins
  • Write Defaults is on in some states and off in others
  • For an Int parameter, the menu control's Value is not the number the transition checks

How to fix it

  1. Test in Unity first: enter Play mode with Gesture Manager or Av3Emulator, press the toggle, and watch whether the parameter and the animator state change
  2. Compare the name in the menu control's Parameter field, in Expression Parameters, and in the Parameters tab of the FX animator - they must match exactly
  3. Make sure the layer is in the animator set as FX on the Avatar Descriptor, and its Weight is 1
  4. Check the transitions: the ON state is entered when the parameter is true (or the Int value), the OFF state when it is false, and Has Exit Time is off
  5. Open the ON and OFF animations in the Animation window. If a property shows "Missing!", rename or move the object back, or record the animation again
  6. Set Write Defaults the same on every state (see the Write Defaults mixture page)
  7. Upload again and test in VRChat

Before you change anything, make a full copy of your project folder so you can go back.
