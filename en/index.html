VRChat Avatar Error Guide

Imported an avatar or outfit into Unity and got pink materials, red Console errors that won't go away, or an upload that fails? Each page explains what the error means, why it happens, and how to fix it step by step. Works whether you use VCC (VRChat Creator Companion) or ALCOM, and whether you bought your avatar on Booth, Gumroad or Jinxxy. (42 errors)

  • VRChat "Security Checks Failed" on an avatar
  • "All compiler errors have to be fixed before you can enter playmode" in a VRChat avatar project
  • "The type or namespace name 'VRC' could not be found" (CS0246)
  • Modular Avatar (nadena.dev) errors in VRChat
  • lilToon errors and pink lilToon materials in VRChat
  • VRChat avatar or outfit turned pink (magenta) in Unity
  • Missing Prefab in Unity (red object names in the Hierarchy)
  • Inspector fields showing "Missing" in Unity
  • "Loaded data for an avatar we do not own, clearing blueprint ID" in VRChat
  • VRChat "Avatar Failed Upload" / "Failed to upload"
  • VRChat SDK "Missing Credentials" even though you're logged in
  • "All pipe instances are busy" when building a VRChat avatar
  • VRChat "VRCExpressionsMenu uses a parameter that is not defined"
  • VRChat avatar over the 256-bit synced parameter limit
  • Unity project path errors: non-English characters or path too long (VRChat)
  • "Failed to resolve packages" in a VRChat project (VCC / ALCOM)
  • Missing Script on a VRChat avatar ("The referenced script on this Behaviour is missing")
  • Dynamic Bone left on a VRChat avatar
  • "Shader error in" Unity (lilToon / Poiyomi)
  • VRChat "You do not have permission to upload"
  • VRChat Blueprint ID problems: detach, reuse, or upload as a new avatar
  • NullReferenceException in a VRChat avatar project
  • Outfit not following the body in VRChat (bone name mismatch)
  • "VRCExpressionsMenu / VRCExpressionParameters object reference is missing"
  • "Gesture Layer needs valid mask on first animator layer"
  • "Images used for Actions & Moods are too large"
  • VRChat audio clip without "Load In Background" enabled
  • "mipmapped textures without 'Streaming Mip Maps' enabled"
  • VRChat "particle systems configured to destroy themselves"
  • VRChat "meshes that were imported with Read/Write disabled"
  • VRChat "Blendshape Normals set to 'Calculate'" / Legacy Blendshape Normals
  • VRChat Quest "Avatar uses unsupported shader" (pink on Quest / Android)
  • VRCFury not installed (VRCFury Missing Script / errors)
  • FaceEmo not installed (Missing Script on facial expression menu)
  • VRChat eyes twitching / blinking during a closed-eye expression
  • VRChat lip sync not working while an expression is on
  • VRChat "This avatar uses a mixture of Write Defaults"
  • VRChat expressions or toggles not working: FX layer weight is 0
  • VRChat "Avatar validation failed" when uploading
  • VRChat PhysBones not working on Quest (hair and skirt don't move)
  • VRChat avatar upload stuck on "Building Avatar" or uploading
  • Uploaded VRChat avatar not showing, or others see a different avatar (robot / fallback)
