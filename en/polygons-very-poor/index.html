What you see on screen:

Triangles: … (SDK Builder panel / rank breakdown)

What it means

Triangles is the total triangle count of every mesh on the avatar. VRChat counts all objects and components, including ones that are turned off, so outfits you keep hidden still add to it. PC limits: Excellent 32,000, and Good, Medium and Poor all 70,000 - one triangle over 70,000 makes the avatar Very Poor. Quest/mobile limits: Excellent 7,500, Good 10,000, Medium 15,000, Poor 20,000. On PC the default Minimum Displayed Performance Rank is Very Poor, so others still see you. On mobile the default is Medium, so with more than 15,000 triangles most mobile users won't see your avatar unless they press Show Avatar.

Common causes

  • Spare outfits and props are kept on the avatar, just turned off (they still count)
  • The full body mesh is kept under the clothes, even the parts no one can see
  • Hair, accessories or outfits bought separately are much higher-poly than the base avatar
  • Several outfits are dressed with Modular Avatar, and each brings its whole mesh
  • The Quest version reuses the PC meshes

How to fix it

  1. Open the SDK Builder panel, expand the rank breakdown and read Triangles
  2. Find the heavy mesh: on each Skinned Mesh Renderer, click the Mesh field to highlight the mesh asset, then select it - the preview at the bottom of the Inspector shows its triangle count
  3. Delete outfits and props you never wear, or move them to a separate copy you don't upload - turning them off does not lower the count
  4. Remove body polygons hidden under clothes with AAO (Avatar Optimizer): Remove Mesh By BlendShape uses the body's shrink shape keys, Remove Mesh By Mask uses a mask image
  5. Lower the polygons of what is still heavy with a reduction tool (for example Blender's Decimate modifier), then check the face and hands keep their shape and shape keys
  6. Tools that run at upload (AAO and other NDMF tools) change the mesh only when you build, so the editor panel can still show the old number - check the rank shown in VRChat after upload
  7. For Quest, work on a duplicate and aim for 15,000 or fewer (Medium) so it shows by default. Limits can change - check the official Avatar Performance Ranking System page on creators.vrchat.com

Before you change anything, make a full copy of your project folder so you can go back.
