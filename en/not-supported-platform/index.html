What you see on screen:

(Avatar unavailable on this platform / Quest friends see a robot instead)

What it means

PC and Quest (Android) versions are uploaded separately. An avatar with no version for the current platform can't be worn there, and other players see a replacement avatar (such as a robot) instead.

Common causes

  • Only the PC version was uploaded, with no Android version
  • The Android version went to a different Blueprint ID
  • An avatar made for Android was uploaded with the build target still on Windows

How to fix it

  1. Duplicate the avatar and make a Quest version (keep the PC original)
  2. Switch the build target to Android
  3. Fix shaders, PhysBones and limits Quest can't handle
  4. Upload it to the same Blueprint ID as the PC version

Before you change anything, make a full copy of your project folder so you can go back.
