VRChat expressions or toggles not working: FX layer weight is 0 - fix

What you see on screen:

(No error message - pressing menu items does nothing)

What it means

A layer in the FX animator still has its Weight set to 0. A layer with weight 0 has no visible effect, no matter what you put in it.

Common causes

  • You added a layer yourself and left the weight at 0
  • The animator was duplicated or rebuilt

How to fix it

  1. In the Animator window, open the animator set as FX on the Avatar Descriptor
  2. Click the gear icon on the layer that doesn't work
  3. Set Weight to 1 (you can ignore the top layer)

Before you change anything, make a full copy of your project folder so you can go back.
