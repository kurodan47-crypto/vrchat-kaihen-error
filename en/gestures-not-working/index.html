VRChat hand gestures not working (face or hands don't change) - fix

What you see on screen:

(No error message - changing your hand shape doesn't change the face or hands)

What it means

Hand shapes (GestureLeft / GestureRight, values 0-7) drive expressions and hands through the Gesture and FX layer animators. If either is missing or misconfigured, nothing happens.

Common causes

  • The Gesture animator was replaced and its first layer has no hand mask (vrc_HandsOnly)
  • An FX layer still has Weight 0
  • Swapping an expression gimmick changed which animator is in the FX slot
  • Write Defaults is mixed on and off
  • Gestures are turned off in VRChat's Action Menu

How to fix it

  1. Check the Gesture and FX slots under Playable Layers on the Avatar Descriptor point to the right animators
  2. Set the first Gesture layer's Mask to vrc_HandsOnly
  3. Set Weight to 1 on FX layers that don't work
  4. Make Write Defaults the same everywhere
  5. Check gestures are turned on in VRChat's Action Menu options

Before you change anything, make a full copy of your project folder so you can go back.
