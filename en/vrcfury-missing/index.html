VRCFury not installed (VRCFury Missing Script / errors) - VRChat fix

What you see on screen:

The referenced script on this Behaviour is missing! / VF.Model … / VRCFury …

What it means

VRCFury, which the outfit or gimmick depends on, is not installed or the wrong version.

Common causes

  • You added a VRCFury-based outfit or gimmick without installing VRCFury itself
  • VRCFury is outdated

How to fix it

  1. Add the VRCFury repository (https://vcc.vrcfury.com) to VCC (or ALCOM)
  2. Install VRCFury in this project (or update it if it's already there)
  3. Reopen Unity and Clear the Console

Before you change anything, make a full copy of your project folder so you can go back.
