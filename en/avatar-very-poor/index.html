What you see on screen:

Performance Rank: Very Poor / Poor (SDK Builder panel or avatar details in VRChat)

What it means

Your performance rank is set by your worst stat: go over any Poor limit and the avatar is Very Poor. On PC the default Minimum Displayed Performance Rank is Very Poor, so others still see it. On Quest/mobile the default is Medium, so Poor and Very Poor avatars are hidden, and users can't set it to show Very Poor (they can still press Show Avatar). On mobile, going Very Poor on PhysBones, Contacts or Constraints removes all of them from the avatar.

Common causes

  • Triangles: PC 70,000 for Good and below (Excellent 32,000); Quest Poor 20,000
  • Texture memory: PC Poor 150 MB / Medium 110 MB / Good 75 MB; Quest Poor 40 MB / Good 18 MB
  • Meshes and materials: skinned meshes PC Poor 16, Quest 2; material slots PC Poor 32, Quest Poor 4
  • Bones: PC Poor 400, Quest Poor 150
  • PhysBones: PC Poor 32 components / 256 affected transforms; Quest Poor 8 / 64
  • Particles, lights, cloth, audio (on Quest, lights, cloth, physics colliders and audio sources are disabled and count as 0)

How to fix it

  1. Open the SDK Builder panel, expand the performance breakdown, and find the worst stat
  2. For textures, lower Max Size and use compression (see the texture memory page)
  3. Delete unused outfit and prop meshes, and merge meshes/materials with a tool such as AAO
  4. Cut PhysBones down to the chains you really need
  5. Make the Quest version on a duplicate and aim for Medium or better (Good if you can)
  6. Limits can change - check the current official table (Avatar Performance Ranking System on creators.vrchat.com)

Before you change anything, make a full copy of your project folder so you can go back.
