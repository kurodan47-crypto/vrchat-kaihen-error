VRChat "Blendshape Normals set to 'Calculate'" / Legacy Blendshape Normals - fix

What you see on screen:

This avatar contains skinned meshes that were imported with Blendshape Normals set to 'Calculate' but aren't using 'Legacy Blendshape Normals'.

What it means

In the model's import settings, Blendshape Normals is set to Calculate but Legacy Blendshape Normals is off. This makes the avatar heavier, so VRChat blocks the upload.

Common causes

  • You added a new outfit or prop model
  • The model's import settings were changed

How to fix it

  1. Select the model file (.fbx) in the Project window
  2. In the Inspector's Model tab, check "Legacy Blendshape Normals" under Blendshape Normals (if it's not there, set Blendshape Normals to Import or None)
  3. Press Apply and upload again

Before you change anything, make a full copy of your project folder so you can go back.
