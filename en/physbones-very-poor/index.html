What you see on screen:

PhysBones Components / Affected Transforms / Colliders / Collision Check Count: … (SDK rank breakdown)

What it means

PhysBones are ranked on four stats. PC limits (Excellent / Good / Medium / Poor): components 4 / 8 / 16 / 32, affected transforms 16 / 64 / 128 / 256, colliders 4 / 8 / 16 / 32, collision checks 32 / 128 / 256 / 512. Go over any Poor value and the avatar is Very Poor. Quest/mobile Poor values are 8 components, 64 transforms, 16 colliders and 64 collision checks - go over them and VRChat removes all PhysBones, Contacts and Constraints from the avatar on mobile, even if someone presses Show Avatar. Turned-off components still count. Collision Check Count is the sum of the PhysBone bones each collider can touch, so one bone touched by three colliders counts three times.

Common causes

  • Every outfit brings its own PhysBones (skirt, ribbons, hood) and they stay even while the outfit is turned off
  • Each hair strand or ribbon has its own PhysBone component instead of one per part
  • Long chains with many bones
  • Long chains list many colliders, which multiplies the collision checks
  • The Quest version reuses the PC PhysBones

How to fix it

  1. Open the SDK Builder panel, expand the rank breakdown and see which of the four PhysBone stats is worst
  2. Delete the PhysBones of outfits and props you never wear - turning them off does not lower the count
  3. Combine chains that belong to one part: put a single PhysBone on their shared parent bone (for example the hair root) - one component moves all child chains. Multi-Child Type Ignore keeps the parent itself still. AAO's Merge PhysBone can also merge components at upload
  4. Remove colliders from chains that don't need them (small accessories, short ribbons) and keep the collider list short on long chains
  5. Remove the PhysBone from short chains that barely show
  6. If you exclude bones with Ignore Transforms, build again and check the number - VRChat users have reported cases where excluded bones still count
  7. For Quest, work on a duplicate, keep hair and skirt first, and stay within 8 components and 64 transforms

Before you change anything, make a full copy of your project folder so you can go back.
