VRChat avatar or outfit turned pink (magenta) in Unity - pink materials fix

What you see on screen:

(No error message - the model just shows up pink)

What it means

When the shader a material uses isn't in the project, Unity draws it pink.

Common causes

  • A shader such as lilToon or Poiyomi is not installed
  • The shader is installed, but the material lost its link to it

How to fix it

  1. Check the "requirements" section of the avatar or outfit readme (from Booth, Gumroad, Jinxxy, etc.)
  2. Install the shader it lists
  3. If it's installed and still pink, select the material and choose the shader again

Before you change anything, make a full copy of your project folder so you can go back.
