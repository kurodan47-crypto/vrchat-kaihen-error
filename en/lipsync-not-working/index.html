VRChat lip sync not working while an expression is on - fix

What you see on screen:

(No error message - lip sync stops only while an expression is shown)

What it means

The expression animation also drives the lip sync blendshapes (vrc.v_aa, etc.). The expression holds the mouth shape, so the mouth doesn't move when you talk.

Common causes

  • You made an expression that includes a mouth shape
  • An expression set or gimmick animation includes vrc.v_ blendshapes

How to fix it

  1. Open the expression animation (.anim) and check for blendshapes starting with vrc.v_
  2. If found, rebuild it with a mouth shape that isn't a lip sync viseme (or delete that row)
  3. If you want lip sync to win while talking, move the mouth part to a separate layer

Before you change anything, make a full copy of your project folder so you can go back.
