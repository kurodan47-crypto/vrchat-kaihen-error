Unity project path errors: non-English characters or path too long (VRChat)

What you see on screen:

Illegal characters in path / PathTooLongException / DirectoryNotFoundException

What it means

The project folder path contains non-English characters or symbols, or it's too long.

Common causes

  • The project is in a folder with non-ASCII characters (e.g. a user name or OneDrive folder in another language)
  • The folder is nested too deeply

How to fix it

  1. Move the project to a short folder with only English letters and numbers (e.g. C:\VRC\Avatar1)
  2. Add it to VCC/ALCOM again and open it from there

Before you change anything, make a full copy of your project folder so you can go back.
