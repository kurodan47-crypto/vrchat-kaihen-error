VRChat "particle systems configured to destroy themselves" - Stop Action fix

What you see on screen:

This avatar contains one or more particle systems configured to destroy themselves when they stop. This is not allowed. Please use a different stop action.

What it means

A particle system's Stop Action is set to Destroy. VRChat doesn't allow objects that destroy themselves when they stop, so the upload is blocked. The same applies to a particle system on the avatar root set to Disable, Trail Renderers with Autodestruct, and collisions that apply force to Pickups.

Common causes

  • You added an emote, pose or effect gimmick
  • You reused an effect from a Unity asset or another game

How to fix it

  1. Select the object with the particle system in the Hierarchy (the error's Select button also works)
  2. In the Inspector, set Stop Action at the top of the Particle System to None or Disable
  3. For trails, uncheck Autodestruct on the Trail Renderer
  4. If Collision is used, remove the Pickup and Item layers from Collides With

Before you change anything, make a full copy of your project folder so you can go back.
