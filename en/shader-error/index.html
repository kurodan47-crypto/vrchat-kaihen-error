"Shader error in" Unity (lilToon / Poiyomi) - VRChat avatar fix

What you see on screen:

Shader error in '…'

What it means

The shader version doesn't match.

Common causes

  • lilToon or Poiyomi is too old or too new
  • The shader is installed twice

How to fix it

  1. Reinstall the shader named in the error, using the version listed in the avatar's readme

Before you change anything, make a full copy of your project folder so you can go back.
