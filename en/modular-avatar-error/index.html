What you see on screen:

nadena.dev.modular_avatar … / ModularAvatar …

What it means

Modular Avatar - the tool most outfits and gimmicks rely on - is missing or the wrong version.

Common causes

  • Modular Avatar is not installed
  • The installed version is older (or newer) than the outfit or gimmick expects

How to fix it

  1. Add Modular Avatar in VCC/ALCOM, or update it to the latest version
  2. If the outfit's readme names a specific version, match it
  3. Reopen Unity and Clear the Console
