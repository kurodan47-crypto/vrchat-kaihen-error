"Images used for Actions & Moods are too large" - VRChat menu icon fix

What you see on screen:

Images used for Actions & Moods are too large.

What it means

An Expressions Menu icon is too large or uncompressed. Icons must be 256x256 or smaller and compressed to upload.

Common causes

  • You added your own icons (large PNGs) to the menu
  • Compression is set to None in the texture settings

How to fix it

  1. Select the icon image in the Project window
  2. In the Inspector, set Max Size to 256 and Compression to Normal Quality
  3. Press Apply and upload again

Before you change anything, make a full copy of your project folder so you can go back.
