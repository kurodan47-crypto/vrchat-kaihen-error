"Failed to resolve packages" in a VRChat project (VCC / ALCOM) - fix

What you see on screen:

Failed to resolve packages / Cannot resolve package

What it means

A required package couldn't be downloaded or loaded.

Common causes

  • Network connection or VPN
  • Outdated package listings in VCC/ALCOM

How to fix it

  1. Check your internet connection and VPN
  2. Reopen the project from VCC (or ALCOM)
  3. Press "Resolve" or reinstall the package

Before you change anything, make a full copy of your project folder so you can go back.
