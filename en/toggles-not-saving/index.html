(No error message - toggles go back to their old state when you put the avatar back on)

What it means

Unless "Saved" is on in Expression Parameters, a parameter goes back to its Default value every time the avatar loads.

Common causes

  • "Saved" is off for that parameter in Expression Parameters
  • The Default value is the opposite of the state you normally want
  • The avatar was reset (values go back to Default)

How to fix it

  1. Open Avatar Descriptor > Expressions > Parameters and check "Saved" for that parameter
  2. Set Default to the state you use most when you put the avatar on
  3. Upload again, change the toggle, switch avatars and back, and check it stayed

Before you change anything, make a full copy of your project folder so you can go back.
