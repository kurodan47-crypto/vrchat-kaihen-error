VRChat改変エラー辞典

uses a parameter that is not defined（メニューのパラメータ）

まずはこれ
  1. Expressions Menu（サブメニューも）を開いて項目を見直す
  2. Expression Parameters に登録するか、その項目を消す

自動で調べたいなら：改変おたすけ診断がこの設定を1クリックで見つけます（無料版あり）。無料で試す

画面に出る文字：

VRCExpressionsMenu uses a parameter that is not defined. Parameter: …

意味

Expressions Menu（手元のメニュー）の項目が、登録されていないパラメータを使っています。

よくある原因

  • ギミックを消したのにメニューだけ残った
  • 衣装のメニューを足したが、パラメータを足し忘れた

直し方

  1. Expressions Menu（サブメニューも）を開いて項目を見直す
  2. Expression Parameters に登録するか、その項目を消す

直す前に、プロジェクトのフォルダを丸ごと複製しておくと安全です。

自動で見つけて直すならUnityのメニューから「診断する」を押すだけで、原因と直し方を日本語で一覧にする無料の道具があります（有料版は多くを1クリックで直します）。
この症状では：登録されていないパラメータの名前を一覧にし、有料版なら型のわかる物を1クリックで登録します。
改変おたすけ診断（無料版あり）

関係するエラー

  • 同期パラメータが256bitを超えている
  • VRCExpressionsMenu / VRCExpressionParameters object reference is missing
  • Gesture Layer needs valid mask on first animator layer（手のマスクが無い）
  • Images used for Actions & Moods are too large（メニューのアイコンが大きすぎる）
